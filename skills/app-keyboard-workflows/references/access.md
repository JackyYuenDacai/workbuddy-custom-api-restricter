# Access 操作手册

适用于 Windows 桌面 Access，先读 [Office 共通操作](office-common.md)。区分数据库文件、导航窗格中的对象、Datasheet 数据记录、Form 表单、Design 设计视图、Query 查询及属性字段。

**数据库与普通文档不同：离开记录可能自动提交数据，Ctrl+S 经常保存对象设计；不能认为“不按保存”就不会改数据库。** 删除/更新查询可能批量修改数据，不能靠输入宏或盲目撤销试验。

| 操作 | 默认键 | 核对点 |
| --- | --- | --- |
| 导航窗格显隐 | `F11` | 查看对象列表，不是全屏 |
| 属性表显隐 | `F4` | 当前对象/控件属性 |
| 切换窗格 | `F6` / `Shift+F6` | 设计网格、属性、导航等随上下文变化 |
| 切换数据库窗口 | `Ctrl+F6` / `Ctrl+Shift+F6` | 核对对象名与视图 |
| 打开所选对象 | `Enter` | 导航窗格中，表单/查询可能有加载事件或提示 |
| 以设计视图打开选中对象 | `Ctrl+Enter` | 仅导航窗格对象焦点；字段内可能插入换行 |
| 查找/替换 | `Ctrl+F/H` | 检查对象、字段、匹配方式；替换会改记录 |
| 当前字段扩大编辑窗口 | `Shift+F2` | Zoom 对话框便于读取长文本；不等于缩放设计画布 |
| 编辑/导航模式切换 | `F2` | Datasheet 中；导航窗格 F2 可能重命名对象 |
| 下/上一字段 | `Tab` / `Shift+Tab` | 可能离开记录并提交修改 |
| 当前记录首/末字段 | `Home` / `End` | 非字段文字编辑模式；核对活动格 |
| 首/末记录 | `Ctrl+Home` / `Ctrl+End` | 导航模式中，选定记录并非排序后的业务“最新” |
| 添加新记录 | `Ctrl+PLUS` | 当前允许新增的记录视图；不是普通放大 |
| 保存当前记录修改 | `Shift+Enter` | 明确提交，核对校验/约束提示 |
| 取消当前编辑 | `Esc` | 一次通常撤销当前字段，再次可能整条记录；只取消尚未提交且确定的改动 |
| 从上条记录复制同字段 | `Ctrl+QUOTE` | 当前字段会被写入，先核对源记录 |
| 插入当前日期 | `Ctrl+SEMICOLON` | 日期格式由区域/字段类型决定 |
| 数据字段内换行 | `Ctrl+Enter` | 只在支持多行的文本字段；注意导航窗格中的不同意义 |
| 保存对象设计 | `Ctrl+S` | 核对是表、查询、表单等对象，不当成记录提交统一键 |
| 关闭活动对象 | `Ctrl+F4` | 可能出现设计保存或数据验证提示 |

**只读检查**：确认数据库和目标对象 → 导航窗格定位 → 打开合适视图 → 查找记录 → 阅读字段/主键 → 不进入编辑或执行动作查询。查询运行是否只读要看具体 SQL/类型，不能凭名称猜测。

**修改一条记录**：核对主键和原值 → 确定字段 → F2 或 Zoom 编辑 → 核对新值 → 按已有授权提交 → 再次定位主键验证。出现关系约束/重复键错误，先解释原因，不换主键或关闭校验来绕过。

**设计更改**：先明确对象和备份/版本需求 → 设计视图 → 修改指定属性 → 核对影响 → 保存。不要将可见界面的字段删除理解为仅删除显示内容；表结构修改可能影响数据与其他对象。

来源：[Microsoft Access shortcuts](https://support.microsoft.com/en-us/accessibility/access/keyboard-shortcuts-for-access)，2026-09-09 查阅。某些键的意义与焦点强相关，本表不授权执行宏、动作查询或删除数据。

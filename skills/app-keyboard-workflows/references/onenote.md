# OneNote 操作手册

适用于当前 Windows 桌面 OneNote，先读 [Office 共通操作](office-common.md)。旧版 OneNote for Windows 10、网页版和 Mac 不保证同键。确认笔记本、分区、页面和同步账号；正文是多个容器，不是一份连续 Word 文档。

| 操作 | 默认键 | 核对 |
| --- | --- | --- |
| 新页面 | `Ctrl+N` | 当前分区中创建，核对标题与位置 |
| 新分区 | `Ctrl+T` | 核对目标笔记本，避免同名分区 |
| 搜索所有笔记本 | `Ctrl+E` | 检查实际范围及打开的笔记本 |
| 当前页面查找 | `Ctrl+F` | 区别于全局搜索 |
| 页面标题 | `Ctrl+Shift+T` | 核对焦点确已到标题字段 |
| 当前分区前/后页面 | `Ctrl+PageUp/PageDown` | 检查页标题，含子页 |
| 后/前分区 | `Ctrl+Tab` / `Ctrl+Shift+Tab` | 顺序依当前界面，不用于正文插入 Tab |
| 页面/窗格导航 | `F6` / `Shift+F6` | 当前版本窗格顺序需观察 |
| 粗体/斜体/下划线 | `Ctrl+B/I/U` | 当前选区或后续输入 |
| 标题 1/2/3 | `Ctrl+Alt+1/2/3` | 使用真实标题样式 |
| 待办标记 | `Ctrl+1` | 可能创建、勾选或清除标记，核对当前状态 |
| 超链接 | `Ctrl+K` | 可链接网页或笔记对象，核对目标 |
| 插入日期 | `Alt+Shift+D` | 当前光标位置；不等于日期时间一起 |
| 插入时间 | `Alt+Shift+T` | 依据本机时间与区域格式 |
| 插入日期和时间 | `Alt+Shift+F` | 核对显示内容 |
| 页面全屏视图 | `F11` | 切换显示，区别于其他 Office 应用 |
| 同步当前笔记本 | `Shift+F9` | 触发后观察同步错误，不能宣称已经云端同步 |
| 同步所有笔记本 | `F9` | 范围比当前页面大，按需求使用 |
| 打印 | `Ctrl+P` | 自由布局容器可能跨页，检查预览 |

**整理会议笔记**：选择正确笔记本/分区 → Ctrl+N → 核对标题焦点并输入标题 → 正文建立标题/段落/待办 → 检查容器顺序 → 核对同步状态。Ctrl+A 的范围可能逐层扩展，不先确认就删除会影响更多笔记。

**找笔记并更新待办**：全局搜索关键词 → 核对笔记本、分区、页标题和日期 → 定位任务段落 → 检查原勾选状态 → 切换一次 → 核对。反复 Ctrl+1 不保证得到“已完成”。

OneNote 通常自动保存；另存为快捷键不能套用 Word 的 F12。分享笔记本、改权限、导出和发送页面另按用户需求处理。输入 Ctrl+Shift+M 等历史 Quick Note 热键前，先核对当前版本，避免创建与目标无关的笔记。

来源：[Microsoft OneNote shortcuts](https://support.microsoft.com/en-us/accessibility/onenote/keyboard-shortcuts-in-onenote)，2026-09-09 查阅；部分同页快捷键依版本不同，未验证的配置以本机帮助为准。

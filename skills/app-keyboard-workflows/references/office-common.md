# Office 共通操作：Windows 桌面版

本章适用于 Microsoft 365 / Office Windows 桌面应用。网页 Office、Mac、WPS、LibreOffice 不保证同键；远程桌面可能截获系统键。Outlook 先区分经典版与新版。应用自定义绑定、语言、输入法、插件优先于默认表。

## 图标不清时的入口

| 目标 | 默认键 | 正确使用 |
| --- | --- | --- |
| 显示 Ribbon KeyTips | `Alt` 或 `F10` | 先释放，读取当前屏幕上字母；再依次选标签和命令，不把整个路径同时按住 |
| 搜索应用命令 | `Alt+Q` | 支持的现代 Office 中进入 Search/Tell Me；确认是应用命令搜索，不是文档查找 |
| 窗格循环 | `F6` / `Shift+F6` | 正文/工作表、Ribbon、状态栏、任务窗格等；次序随布局变化 |
| 当前控件组导航 | `Tab` / `Shift+Tab`、方向键 | 核对焦点框/控件名称，不按固定 Tab 次数 |
| 上下文菜单 | `Shift+F10` / `APPS` | 根据当前文字、单元格、对象或列表选择打开 |
| Ribbon 折叠/展开 | `Ctrl+F1` | 切换状态；勿在未知状态重复按 |
| 关闭当前弹层 | `Esc` | 一层一次；可能取消编辑，不是通用退出全部操作 |
| 帮助 | `F1` | 可能打开帮助任务窗格/网页；不等于业务操作完成 |

**KeyTips 流程**：确认应用与文档 → Alt → 新观察读取标签字母 → 按字母 → 新观察读取命令字母 → 选择 → 核对对话框/结果。英文版常见 File/Home/Insert/Review/View 字母为 F/H/N/R/W，但不要把它们当作跨语言保证。若某版支持 `Alt+Q`，可以直接搜索“另存为”“插入表格”“选择窗格”等本地化命令；选择前核对具体命令，搜索结果可能含帮助条目。

`sequence` 适合已经核实且仍在同一窗口的一项短快捷操作；KeyTips 未确认、菜单需等待、弹窗更换前台窗口时拆开操作。序列中断后检查已打开的菜单，不重发完整链。

## 文档、剪贴板和保存

| 目标 | 常见键 | 边界 |
| --- | --- | --- |
| 打开 | `Ctrl+O` | 可能先进入 Backstage；核对本地/云端路径 |
| 新建 | `Ctrl+N` | 新文档/工作簿/演示文稿；Outlook 依当前模块，新建对象可能不同 |
| 保存 | `Ctrl+S` | 初次保存可能出现对话框；Access 数据记录与对象设计另有语义 |
| 另存为 | `F12`（Word/Excel/PowerPoint 桌面版） | 核对路径、格式和覆盖提示；其他应用不套用 |
| 打印入口 | `Ctrl+P` | 打开预览不等于已经打印；核对打印机、范围、份数后才最终打印 |
| 关闭当前文档 | `Ctrl+F4` | 可能有未保存提示；不默认丢弃 |
| 复制/剪切/粘贴 | `Ctrl+C/X/V` | 先确认选区和剪贴板来源；V 可能携带格式、公式或链接 |
| 撤销 | `Ctrl+Z` | 只撤销明确属于当前任务的最近操作；云协作和数据库提交不保证可撤销 |
| 重做/重复 | `Ctrl+Y` | 不总是重做；可能重复最近动作 |

保存对话框中可用 `Ctrl+L` / `Alt+D` 聚焦路径栏（以当前对话框为准），但**不是所有 Office 正文的地址栏快捷键**。确认“文件名”控件后输入文件名，明确选择格式，再执行保存。观察文档标题/保存状态；有文件工具时验证目标文件存在、扩展名正确。不要仅因对话框消失就宣称文件格式正确。

AutoSave 打开时，修改可能立即同步；Ctrl+S 不是唯一写入时点。受保护视图、只读、共享权限、密码或 UAC 不能靠快捷键绕过，也不要为使快捷键成功自动启用宏。

## 键名、布局与多行

`Ctrl+Shift+>` 是字符表示；美式键盘常用工具参数 `CTRL+SHIFT+PERIOD`。`Ctrl+;` 为 `CTRL+SEMICOLON`，`Ctrl+Shift+:` 对应 `CTRL+SHIFT+SEMICOLON`；`Ctrl+~` 对应 `CTRL+SHIFT+BACKTICK`。其他布局用应用菜单核对，不能假设字符=同一物理键。

Ctrl 加主键区加号用 `CTRL+PLUS` / `CTRL++`；数字小键盘加号是 `CTRL+ADD`。`NUMPAD_ENTER`、`NUMPAD0`…`NUMPAD9` 与主键区数字/Enter 不同。公式和文字用 Unicode 输入工具；快捷键工具不是任意文本输入器。

换行需读对应应用：Word Enter 新段落、Shift+Enter 软换行；Excel Alt+Enter 单元格内换行；Outlook Ctrl+Enter 可能发送邮件。不能跨应用照搬。

## 完成检查

导航：文档身份 + 实际目标位置。编辑：目标选区 + 内容/公式/对象属性。保存：路径/格式 + 保存状态。打印/发送/发布：按用户已有授权执行一次，再核对输出状态；失败/超时不自动重复最终动作。

Microsoft 来源及版本说明见各应用章节。指南覆盖常用完整工作流，不保证每个历史版本、插件或自定义功能的所有键位。

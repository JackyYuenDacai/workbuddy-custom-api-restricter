# Excel 操作手册

先读 [Office 共通操作](office-common.md)。焦点状态至少分：单元格选择、单元格编辑、公式栏、名称框、筛选菜单、图表/形状与对话框。名称框/公式栏文字与行列标题比猜单元格坐标可靠。

## 导航与选择

| 操作 | 默认键 | 注意 |
| --- | --- | --- |
| 转到单元格/范围 | `Ctrl+G` / `F5` | 输入 `D12`、`A1:D20` 或命名范围；核对名称框/选区 |
| 查找/替换 | `Ctrl+F/H` | 核对工作表/工作簿、公式/值、大小写与完整单元格匹配 |
| 当前区域边界 | `Ctrl+方向键` | 空白行列会改变落点；不等于表格最后记录 |
| 工作表起点 | `Ctrl+Home` | 通常 A1，冻结窗格可能影响可视位置 |
| 最后使用单元格 | `Ctrl+End` | 含格式残留，不能当成真实数据末行 |
| 扩展到区域边界 | `Ctrl+Shift+方向键` | 核对是否跨越空白/隐藏区 |
| 选择整列/整行 | `Ctrl+Space` / `Shift+Space` | 输入法可能截获 Ctrl+Space；编辑模式下不同 |
| 当前区域/全表 | `Ctrl+A` | 依上下文和次数，不能盲认全表 |
| 前/后工作表 | `Ctrl+PageUp/PageDown` | 核对标签，注意隐藏工作表 |
| 当前窗格切换 | `F6` / `Shift+F6` | 包括 Ribbon、窗格与工作表 |

## 输入、公式和计算

| 操作 | 默认键 | 注意 |
| --- | --- | --- |
| 编辑活动单元格 | `F2` | 编辑已有内容；直接打字通常覆盖整格 |
| 接受/取消当前编辑 | `Enter` / `Esc` | Enter 后移动方向可配置；Esc 取消未提交编辑 |
| 单元格内换行 | `Alt+Enter` | 不会自动开启所有需要的行高/换行显示 |
| 同一内容填入选区 | `Ctrl+Enter` | 会写多个格，先核对范围 |
| 向下/右填充 | `Ctrl+D/R` | 用选区首行/列覆盖其余内容，公式相对引用会调整 |
| 绝对/相对引用循环 | `F4` | 公式编辑中 `$A$1 → A$1 → $A1 → A1`；非编辑时可能重复动作 |
| 自动求和 | `Alt+=`（`ALT+EQUAL`） | 核对建议范围，不能直接相信自动识别 |
| 插入函数对话框 | `Shift+F3` | 核对函数名、参数和区域分隔符 |
| 显示公式/结果 | `Ctrl+BACKTICK` | 依键盘布局；不是计算 |
| 日期/时间常量 | `Ctrl+;` / `Ctrl+Shift+;` | 插入当前值，不是动态 TODAY/NOW 公式 |
| 计算打开的工作簿 | `F9` | 编辑公式时可能把选中表达式求值成常量！先退出编辑 |
| 计算活动工作表 | `Shift+F9` | 核对计算模式与实际结果 |
| 强制完整计算 | `Ctrl+Alt+F9` | 可能耗时，按需求使用 |

## 格式、表格与数据

| 操作 | 默认键 | 注意 |
| --- | --- | --- |
| 设置单元格格式 | `Ctrl+1` | 数字格式、对齐、边框等；核对选区 |
| 粗体/斜体/下划线 | `Ctrl+B/I/U` | 与数据类型无关 |
| 常规/数字/百分比 | `Ctrl+Shift+BACKTICK` / `Ctrl+Shift+1` / `Ctrl+Shift+5` | 美式键位；百分比 0.25 显示 25%，不自动改原数值 |
| 建表 | `Ctrl+T` / `Ctrl+L` | 核对范围与“表包含标题”；Excel Ctrl+L 不是地址栏 |
| 筛选开/关 | `Ctrl+Shift+L` | 区分添加筛选按钮与清除具体筛选 |
| 打开筛选/下拉列表 | `Alt+Down` | 需要相应表头/单元格焦点；也可能是数据验证列表 |
| 仅选择可见单元格 | `Alt+;`（`ALT+SEMICOLON`） | 操作过滤后的数据前检查可见范围 |
| 选择性粘贴 | `Ctrl+Alt+V` | 对话框核对值/公式/格式/转置；不用固定字母跨语言选择 |
| 插入单元格/行列 | `Ctrl+PLUS` | 依当前选区，核对右移/下移/整行列 |
| 删除单元格/行列 | `Ctrl+MINUS` | 与 Delete 清除内容不同；确认范围 |
| 清除所选内容 | `Delete` | 通常保留格式；筛选或多区域选区需要特别核对 |
| 新工作表 | `Shift+F11` | 核对新增标签，不等于新工作簿 |
| 当前表内图表 | `Alt+F1` | 核对系列/分类范围；F11 常创建图表工作表 |

## 工作流与易错点

**准确修改 D12**：Ctrl+G → D12 → 确认名称框与原值 → 要改局部则 F2，要替换整格才直接输入 → Enter → 重新定位并核对公式栏/值 → 保存。

**填充公式**：确认首格公式 → Ctrl+G 选择完整目标区域 → Ctrl+D 或 Ctrl+R → 核对起点、中间、末端的相对/绝对引用和结果。先检查合并单元格、筛选、表格计算列是否改变行为。

**排序/筛选**：识别整个表和标题 → 打开筛选或排序入口 → 读取字段/顺序/范围 → 核对完整行仍对应。不要只排序一列而破坏记录；出现“扩展选定区域”先判断数据结构。

**导出**：先保存工作簿 → 另存为核对格式；CSV 可能仅导出活动表并丢失公式/格式/多表信息，必须符合用户目标。PDF 先核对打印区域、缩放和分页。

方向键只滚动不换活动格时检查 Scroll Lock；不要连续按键试探。`####` 可能是列宽或日期显示问题，不等于数据丢失。公式作为文字时检查前导单引号、文本格式和公式显示模式。受保护表不能通过解除保护绕过用户权限。

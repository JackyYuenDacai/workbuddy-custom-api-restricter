# QQ / QQNT — Windows

QQ 经典版与新版 QQNT 的全局热键、搜索和发送键可以不同，还可能被微信、截图工具或输入法占用。不能把下面的经典默认候选当作已验证的本机设置。第一次需要某项热键时，在 QQ 设置的“快捷键/热键”与聊天输入框“发送”旁的选项中核对，并记录当前会话有效的绑定；不要改用户的发送习惯。

## 常用入口和按键

| 目标 | 按键/入口 | 适用性与结果核对 |
| --- | --- | --- |
| 恢复现有 QQ | 主技能的窗口 ID、任务栏、系统托盘流程 | 窗口列表缺失不等于退出；先查隐藏图标，不直接启动第二实例 |
| 提取/打开消息 | `Ctrl+Alt+Z` | 经典版常见默认，可更改/禁用；可能跳到未读联系人，不保证目标聊天 |
| 截图 | `Ctrl+Alt+A` | 常见可配置全局热键；可能打开 QQ 或别的软件截图层，不能作为“查 QQ 在不在”的探测 |
| 搜索联系人/群 | 主窗口搜索框；仅在当前版本明确显示时用其搜索快捷键 | 不假定 Ctrl+F 一定是联系人搜索；确认搜索范围再输入姓名/号码 |
| 搜索当前聊天 | 当前会话中的“聊天记录/搜索”入口 | QQNT/经典版入口和绑定不同；Ctrl+F 仅在菜单/设置确认后使用 |
| 列表选择 | `Up` / `Down` | 先确认焦点在搜索结果/联系人列表，核对选中项身份 |
| 打开所选联系人 | `Enter` | 只在已确认结果列表焦点时；聊天输入框里的同一键可能发送 |
| 字段切换 | `Tab` / `Shift+Tab` | 逐步核对控件，不用固定 Tab 次数猜输入框 |
| 关闭已知弹层 | `Esc` | 先判断是否截图层、搜索、候选窗或聊天窗口；不盲目重复 |
| 文本全选/修改 | `Ctrl+A`、方向键、Backspace | 仅在已确认的消息编辑框中；消息列表全选可能是另一操作 |
| 发送消息 | `Enter` 或 `Ctrl+Enter` | 以“发送”按钮选项的当前设置为准；执行前核对联系人、完整内容与已有发送授权 |
| 换行 | 当前发送模式对应的换行方式，常见为 `Ctrl+Enter` 或 `Enter` | 不能拿真实消息试验哪一个会发送；Shift+Enter 也不能跨版本保证 |

**特别注意**：文字输入工具仍拒绝换行/控制字符，但 0.6.0 的键盘工具支持 `CTRL+ENTER` / `SHIFT+ENTER`。已从设置确认哪一键换行后，可以分段输入并用该换行键连接，每次观察核对。若发送模式未知，先查设置，不能拿真实消息试键，不偷偷改成一行或分多次发送。

## 恢复、搜索、撰写

1. 根据 QQ 标题/进程找到当前窗口；托盘恢复时读取已出现的 tooltip，常在图标上方，也可能在旁边。把提示文字与当前图标关联；不点击 tooltip 本身。仅当工具支持 hover 时才用悬停产生提示；不要拿未知图标点击代替悬停。
2. 激活后确认账号和目标联系人/群。昵称重名时结合 QQ 号、群名或用户提供的身份；不会因为“打开了一个聊天”就认为目标正确。
3. 从主窗口搜索定位联系人，核对结果，再打开。进入会话后确认聊天标题，随后聚焦输入框。
4. 写入草稿后核对全文。用户只要求准备/编辑时保留草稿；用户已明确要求向该联系人发送这些内容时，不重复索取同一授权，核对当前发送键后执行一次。
5. 查看消息气泡及发送状态；超时或界面无反馈时先核对是否已经发送，不重发来验证。登录、验证码或密码由用户处理。

## 本机热键登记与更完整的任务路线

**批量按群号/好友号和日期导出**：优先补充技能 [qq-message-export](../../qq-message-export/SKILL.md)，使用本地 QCE 的会话查找、时间过滤和导出任务工具，比逐条滚动复制更适合长记录。需要后端已启动并登录；QQNT 本身不保证提供相同 API。群号与群内发送人 QQ 号是不同条件。

QQ 的“完整指南”应包含确认键位的办法，而不是把经典版候选填成 QQNT 保证可用的表。第一次查看设置时按以下字段记录在当前会话；不修改原设置：

| 项目 | 需要读取的实际值 | 执行后的证据 |
| --- | --- | --- |
| 版本/账号 | QQNT 或经典版、版本号、当前账号 | 设置/主窗口身份 |
| 提取消息热键 | 当前组合键、是否启用、是否冲突 | 恢复后的聊天标题；可能是最新未读而非目标 |
| 截图热键 | 组合键及工具归属 | 截图层的品牌、按钮/提示 |
| 发送方式 | Enter 发送或 Ctrl+Enter 发送 | 发送按钮选项中的选中状态 |
| 换行方式 | 与当前发送方式相配的实际绑定 | 以设置说明为准，不用真实消息试验 |
| 搜索范围 | 联系人/群/当前聊天/全局消息 | 搜索栏标签、搜索结果分类 |
| 关闭窗口行为 | 关闭窗口或最小化到托盘 | 窗口/托盘状态，不以任务栏消失判定退出 |

**查聊天记录**：从正确聊天进入记录搜索 → 指定关键词/日期/文件类型 → 核对发送人、时间和前后消息 → 回到原会话核对标题。全局搜索同名结果与当前聊天记录不是同一范围。

**准备多段消息**：先读取发送/换行设置 → 聚焦正确聊天输入框 → 分段输入与已确认的换行键 → 检查完整草稿与附件 → 根据请求保存草稿或发送一次。输入工具每次最多 2000 字符时按段分次输入；切分不能偷偷改变消息边界或发送次数。

**发送文件**：进入目标聊天 → 通过已识别的“文件”入口打开选择器 → 核对路径、文件名、类型与实际附件预览 → 按已有发送授权提交 → 核对传输完成/失败状态。`Ctrl+V` 若剪贴板是文件或图片，可能形成附件或发送预览；不要把它当作保证只粘贴文字。

**截图**：任务确需截图时才使用已核实热键 → 核对截图层 → 选择区域并检查预览 → 区分复制、保存、取消、发送。截图完成不自动授权发给当前聊天。

**修改草稿**：确认输入框焦点 → Ctrl+Home/End、Ctrl+Left/Right 和加 Shift 的选择键可用于标准文本编辑；富文本控件、表情块和引用消息可能改变光标行为，按结果核对。Ctrl+A 后先确认仅选中草稿再替换。

**托盘找不到**：按主技能检查任务栏和隐藏图标；若提示显示在图标上方/旁边，读取名称并关联其指向的图标。QQ 可能正在登录、后台运行或有独立会话窗口；先恢复已有实例，不反复启动。需要菜单时在已识别图标上打开上下文菜单并读项目。

**无响应恢复**：先查模态文件选择器、截图层、输入法候选、快捷键冲突和焦点。已确认弹层用一次 Esc 退出后重新观察。聊天发送结果不明时先读消息气泡/失败标记；禁止用第二次发送作为验证。

## 来源与置信度

QQ 没有在本次核验中取得覆盖经典版和 QQNT 的统一官方键位表，也没有读取用户聊天内容来测试。`Ctrl+Alt+Z` 与 `Ctrl+Alt+A` 仅作为经典常见绑定候选；本机设置、菜单提示及发送方式选项是最终依据。不要编造未经确认的“快速打开联系人”组合键。

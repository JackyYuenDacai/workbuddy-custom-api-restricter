# Word 操作手册

先读 [Office 共通操作](office-common.md)。适用于 Windows 桌面 Word；区分正文、导航窗格、表格、页眉页脚、批注编辑框和对话框。

## 阅读、定位和选择

| 操作 | 默认键 | 核对 |
| --- | --- | --- |
| 导航/查找 | `Ctrl+F` | 输入关键词，检查结果和当前位置 |
| 替换 | `Ctrl+H` | 先检查查找条件、格式和范围；不默认全部替换 |
| 转到页/节/书签等 | `Ctrl+G` / `F5` | 确认 Go To 类型，再输入目标 |
| 文档首/尾 | `Ctrl+Home` / `Ctrl+End` | 正文焦点；窗格中可能是列表首尾 |
| 上/下单词 | `Ctrl+Left` / `Ctrl+Right` | 编辑光标移动 |
| 上/下段落 | `Ctrl+Up` / `Ctrl+Down` | 核对目标段落 |
| 扩展字符/单词选区 | `Shift+方向键` / `Ctrl+Shift+Left/Right` | 核对选区首尾 |
| 选到行首/行尾 | `Shift+Home` / `Shift+End` | 视觉行，不一定完整段落 |
| 扩展到文档首/尾 | `Ctrl+Shift+Home/End` | 很大选区；修改前核对 |
| 全选 | `Ctrl+A` | 焦点在正文或当前字段，作用域不同 |
| 返回上次编辑位置 | `Shift+F5` | 核对实际定位，不假定与上次阅读位置相同 |

## 样式和排版

| 操作 | 默认键 | 注意 |
| --- | --- | --- |
| 粗体/斜体/下划线 | `Ctrl+B/I/U` | 切换；无选区时影响后续输入 |
| 字体对话框 | `Ctrl+D` | 用数值和控件名称核对字体/字号 |
| 字号增/减 1 磅 | `Ctrl+]` / `Ctrl+[` | 工具为 RBRACKET/LBRACKET |
| 居中/左/右/两端对齐 | `Ctrl+E/L/R/J` | 段落级，不是整页布局 |
| 单倍/双倍/1.5 倍行距 | `Ctrl+1/2/5` | 当前段落或选中段落 |
| 增/减段落缩进 | `Ctrl+M` / `Ctrl+Shift+M` | 不用空格模拟缩进 |
| 悬挂缩进/减小 | `Ctrl+T` / `Ctrl+Shift+T` | 核对标尺/段落设置 |
| 正文样式 | `Ctrl+Shift+N` | 应用 Normal，不保证删除所有直接格式 |
| 标题 1/2/3 | `Ctrl+Alt+1/2/3` | 优先真实标题样式，便于导航和目录 |
| 应用样式入口 | `Ctrl+Shift+S` | 样式名称依本地化和模板 |
| 显示格式标记 | `Ctrl+Shift+8` | ¶ 显示/隐藏；不是插入段落符 |
| 清除直接字符格式 | `Ctrl+Space` | 中文环境可能被输入法占用；改用命令搜索 |
| 清除直接段落格式 | `Ctrl+Q` | 不当作退出程序 |
| 切换大小写 | `Shift+F3` | 核对所选文字，中文一般不受影响 |

## 插入、表格和审阅

| 操作 | 默认键 | 注意 |
| --- | --- | --- |
| 新段落/软换行 | `Enter` / `Shift+Enter` | 两者有不同段落样式与间距结果 |
| 分页符 | `Ctrl+Enter` | 不用多次 Enter 撑到下一页 |
| 超链接 | `Ctrl+K` | 核对显示文本和链接地址 |
| 脚注/尾注 | `Ctrl+Alt+F` / `Ctrl+Alt+D` | 依模板编号，核对位置 |
| 表格下/上一格 | `Tab` / `Shift+Tab` | 最后一格的 Tab 会新增一行 |
| 表格内插入制表符 | `Ctrl+Tab` | 不离开单元格 |
| 拼写/编辑器 | `F7` | 当前版本可能显示 Editor；建议不是自动接受 |
| 插入批注 | `Ctrl+Alt+M` | 某些现代批注需要 Post；创建编辑框≠已发布 |
| 修订开/关 | `Ctrl+Shift+E` | 先确认当前状态与用户意图，别无意关闭审阅 |
| 更新所选域 | `F9` | 链接、目录和域可能变化；核对提示与结果 |
| 域代码/结果切换 | `Alt+F9` | 改显示模式，不等于刷新数据 |

Microsoft 365 新版中 `Ctrl+Shift+V` 通常是“仅粘贴文本”；旧版曾用于粘贴格式，不能按旧经验操作。Paste Special/Format Painter 用菜单或命令搜索确认当前绑定。

## 工作流

**修改特定段落**：Ctrl+F 搜索唯一片段 → 核对页码/前后文 → 回到正文并准确选择 → 输入替换 → 核对内容及样式 → 按请求保存。查找框仍有焦点时 Ctrl+A 只会选搜索词。

**制作结构化文档**：输入标题/正文 → 用标题样式分级 → 插入真正分页符和表格 → 命令搜索插入目录 → 更新并查看分页 → 保存。不要用一串空格、Tab 和空段落模仿布局。

**审阅并保留修订**：确认文档/修订状态 → 开启或保留 Track Changes → 编辑 → 按需批注 → 阅读审阅窗格 → 保存；不自动接受所有修订。

**导出 PDF**：保存原稿 → F12 或命令搜索另存为/导出 → 核对 PDF 类型、路径及范围 → 执行 → 用可用文件/预览工具核对页数、分页、表格和文字。快捷键完成保存不证明视觉排版正确。

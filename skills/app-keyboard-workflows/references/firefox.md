# Mozilla Firefox — Windows

确认目标 Firefox 窗口、标签和是否有模态提示。网页编辑器、PDF 阅读器、扩展和全屏状态可能截获按键；优先浏览器地址栏建立明确焦点。以下是常见 Windows 默认快捷键，以当前版本菜单/工具 schema 为准。

| 操作 | 默认键 | 核对点 |
| --- | --- | --- |
| 聚焦地址栏 | `Ctrl+L` / `Alt+D` / `F6` | 首选 Ctrl+L；F6 的结果依当前焦点，可能只是循环到另一窗格 |
| 导航 | 地址栏输入 URL 后 `Enter` | 核对输入域确为地址栏；加载后验证实际 URL 和页面 |
| 新标签 | `Ctrl+T` | 仅在需要新标签时；复用已有标签不要重开 |
| 关闭/恢复标签 | `Ctrl+W` / `Ctrl+Shift+T` | 关闭前检查未提交表单；恢复后核对 URL |
| 下/上标签 | `Ctrl+PageDown` / `Ctrl+PageUp` | 相邻标签，核对标题 |
| 按序选择标签 | `Ctrl+1`…`Ctrl+8`；`Ctrl+9` 最后一个 | 只在标签顺序已知时使用 |
| Ctrl+Tab 标签切换 | `Ctrl+Tab` / `Ctrl+Shift+Tab` | “按最近使用顺序切换”设置会改变顺序；不要默认相邻 |
| 后退/前进 | `Alt+Left` / `Alt+Right` | 可能离开未保存表单；返回后核对页面 |
| 刷新 | `Ctrl+R` / `F5` | 表单提交结果未知时避免刷新造成重发 |
| 忽略缓存刷新 | `Ctrl+Shift+R` / `Ctrl+F5` | 仅排查陈旧页面时；不是清除登录/所有缓存 |
| 停止加载/关闭查找 | `Esc` | 结果依当前模式；不是统一“回主界面” |
| 页面查找 | `Ctrl+F` | 显示查找条；可用文字定位替代猜图标 |
| 下一个/上一个匹配 | `F3` / `Shift+F3` | 核对匹配文本；找到文字不等于已点链接 |
| 页面缩放 | `Ctrl++` / `Ctrl+-` / `Ctrl+0` | `Ctrl++` 为 Ctrl 加加号键，工具表示依 schema；0 复位 |
| 浏览器菜单 | `Alt`，再方向键 | Windows 隐藏菜单栏可临时显示；菜单助记字母依语言 |
| 英文界面的 File 菜单 | `Alt+F` | 菜单助记字母依语言；不是通用的“三横线”应用菜单快捷键 |
| 全屏 | `F11` | 先判断当前状态；切换后重新核对窗口 |
| 下载列表 | `Ctrl+J` | 打开列表不等于授权打开/运行下载文件 |
| 历史侧栏 | `Ctrl+H` | 只查看任务相关历史 |
| 书签侧栏 | `Ctrl+B` | 与 VS Code 同键但用途不同 |
| 保存页面/打印 | `Ctrl+S` / `Ctrl+P` | 会进入保存/打印流程，不作为导航恢复 |

## 标签、书签、表单与阅读

| 目标 | 常见 Windows 默认键 | 焦点/版本说明 |
| --- | --- | --- |
| 新窗口 | `Ctrl+N` | 区别于 Ctrl+T 新标签；新窗口需重新确认目标 |
| 新隐私窗口 | `Ctrl+Shift+P` | 不继承普通窗口全部会话状态，不等于匿名网络 |
| 恢复关闭的窗口 | `Ctrl+Shift+N` | 先确认确实需要恢复，避免恢复不相关会话 |
| 给当前页加书签 | `Ctrl+D` | 核对标题、URL、保存目录；可能打开已有书签编辑 |
| 书签管理 Library | `Ctrl+Shift+O` | 新窗口需重新识别焦点 |
| 历史 Library | `Ctrl+Shift+H` | 与 Ctrl+H 侧栏区别 |
| 页内查找文字 | `Ctrl+F` | 不含站点尚未加载或折叠的内容 |
| 快速查找文字/链接 | `/` / `QUOTE` | 仅非输入框焦点；网页可能截获，以实际状态为准 |
| 页面上/下滚动 | `PageUp/PageDown` | 文本框或嵌入 PDF 有自己的滚动范围 |
| 下/上滚一屏 | `Space` / `Shift+Space` | 仅页面背景焦点；按钮/复选框上会激活 |
| 页面顶部/底部 | `Ctrl+Home/End` | 输入框焦点时移动文字光标 |
| 下/上一可聚焦控件 | `Tab` / `Shift+Tab` | 用焦点框、控件名称或状态栏链接验证 |
| 激活已聚焦链接 | `Enter` | 核对链接地址；表单按钮上可提交 |
| 打开已聚焦链接到新标签 | `Alt+Enter` | 焦点必须是链接；地址栏也可能新标签导航 |
| 阅读模式 | `F9` | 仅支持的文章页；可能无效，不反复按 |
| 清除历史对话框 | `Ctrl+Shift+Delete` | 仅打开入口；不要默认清除全部数据 |

下载、打印、保存页面和书签对话框可能成为独立窗口。不要用一个 `sequence` 连续切窗口并确认路径；每次核对新窗口和文件名。地址栏建议可以包含历史、书签和远程搜索，Enter 前检查最终字符串与候选，不仅检查输入的关键词。

**内置 PDF**：先确认 Firefox PDF 阅读器。页面查找、缩放与打印可能由阅读器处理；优先读取工具栏的页码、总页数、缩放框和下载控件名称。PDF 扫描图没有可搜索文本时，零匹配不等于内容不存在。不要把普通网页 Home/End 的结果当成 PDF 页号定位成功。

**表单**：Tab 导航到字段 → 读取标签/当前值 → 编辑 → 验证值与验证错误。Space 在复选框切换勾选；箭头在单选组或下拉项改变选项。输入法候选仍显示时 Enter 可能只提交候选词。表单发送由明确的目标按钮及已有用户授权决定，不靠连续 Enter 猜测。

## 可靠工作流

**导航已有窗口**：确认 Firefox → Ctrl+L → 确认地址栏焦点 → 输入用户指定地址 → 确认文字 → Enter → 核对 URL、标题及目标页面内容。地址相同但显示登录或错误页，不能报告页面任务完成。

**链接太小**：Ctrl+F 搜索已知可见文字 → 核对命中 → 用可访问性链接节点或新截图点击目标；不要假定 Enter 在查找栏里会打开链接。若只有图形按钮，页面缩放可以辅助观察，但不能创造不存在的控件语义。

**恢复页内焦点**：Esc 关闭已确认的查找/菜单 → 用 F6 或 Tab 切到页面并检查焦点；不要用固定 Tab 次数定位付款、发送或删除按钮。空格在网页可能滚动、勾选复选框或激活控件，Enter 可能提交表单。

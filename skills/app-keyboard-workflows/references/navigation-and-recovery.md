# Windows 快捷操作与故障排查

本章用于跨应用焦点、窗口、菜单、输入法和按键工具。应用专用键见对应章节；窗口枚举、截图令牌、托盘发现沿用当前 computer-use 技能。

## 系统导航入口

| 目标 | Windows 常见键 | 使用条件与结果 |
| --- | --- | --- |
| 应用切换 | `Alt+Tab` / `Alt+Shift+Tab` | 窗口顺序会变，核对切换器/前台标题；不能盲数次数 |
| 任务视图 | `Win+Tab` | 可读标题选择目标，切换后重新观察 |
| 聚焦任务栏 | `Win+T` | 方向键选择，再读应用名/预览，Enter 激活 |
| 通知区域焦点 | `Win+B` | 方向键探索已显示图标；隐藏图标入口需确认后打开 |
| 按任务栏序号激活 | `Win+1`…`Win+9` | 仅已知排列时；可能启动新实例或选择组内窗口 |
| 显示桌面/恢复 | `Win+D` | 切换，会离开当前应用；不是关闭程序 |
| 窗口系统菜单 | `Alt+Space` | 读取移动/大小/最小化等项目，助记字母依语言 |
| 最大化/还原/最小化 | `Win+Up/Down` | Down 结果依初始状态；观察后再决定下一步 |
| 左右贴靠 | `Win+Left/Right` | 可能进入布局选择，核对窗口大小与内容可见性 |
| 移到另一显示器 | `Win+Shift+Left/Right` | 多显示器顺序以实际布局为准 |
| 关闭当前窗口 | `Alt+F4` | 可能关闭整个应用/弹保存提示；不用于恢复未知焦点 |
| 切换输入语言 | `Win+Space` | 读当前输入法；切换后再次核对，不假定一次到英文 |

系统组合键可能使前台离开目标窗口。WorkBuddy 的窗口约束若拒绝跨窗口动作，使用主技能提供的窗口选择接口；不要通过更换虚假的窗口 ID 绕过。动作完成后获取新目标状态/截图令牌。

托盘提示常在图标上方，也可在旁边；将 tooltip 名称与图标位置关联。展开隐藏图标后读取提示或可访问性名称，不从模糊形状猜程序。工具提供 hover 才能悬停；没有 hover 时使用可读名称或键盘焦点证据，不以点击未知图标代替识别。

## 按键表示与 WorkBuddy 参数

| 指南表示 | 键盘工具字段示例 | 含义 |
| --- | --- | --- |
| Ctrl+Shift+P | `key="CTRL+SHIFT+P"` | 同时修饰一个主键，自动释放 |
| Ctrl+K → Ctrl+S | `sequence=["CTRL+K","CTRL+S"]` | 两笔 chord，各笔之间释放 |
| Ctrl+K → Z | `sequence=["CTRL+K","Z"]` | 第二笔不带 Ctrl |
| P → W | `sequence=["P","W"]` | 仅菜单路径已确认时，字母依次按；不是输入字符串 |
| Ctrl+加号 | `key="CTRL+PLUS"` | 主键区加号，隐含相应 Shift；数字小键盘是 ADD |
| Alt+等号 | `key="ALT+EQUAL"` | 不加 Shift，常见 Excel 自动求和 |
| Shift+F10 | `key="SHIFT+F10"` | 当前控件的上下文菜单 |

表格中的 `Ctrl+B/I/U` 是三个可选组合键的简写，必须展开为 `CTRL+B`、`CTRL+I` 或 `CTRL+U`；`Left/Right` 同理。不能把斜杠或箭头原样传给工具。

`local-computer-tools` 0.6.0 支持 Ctrl/Alt/Shift/Win 与左右修饰键、字母、数字、F1–F24、导航、数字小键盘、标点、多媒体和 `VK_0xNN`（08–FE）。罕见 VK 需先核实语义，不代表所有应用都实现该快捷键。Fn 通常由硬件处理，Ctrl+Alt+Delete、安全桌面/UAC 不是普通 SendInput 可保证的范围。

一次调用仅传 key 或 sequence 之一；sequence 为 1–8 笔的一项已知快捷操作，不用它拼接搜索、输入、发送等多阶段宏。工具仍需有效窗口与新截图令牌，并检查焦点、敏感控件和 STOP。实际完整字段以当前 MCP schema 为准；上表只展示按键字段。运行中若仍看到旧 enum，重新连接 MCP 后发现 schema。

文本用 Unicode 输入工具，按键用键盘工具。当前文字工具每次最多 2000 字符且不接收换行/控制字符；多段文字按应用已确认的换行方式连接，再核对完整内容。不要用数字 VK 枚举来代替任意 Unicode 文本。

## 故障诊断表

| 症状 | 先检查 | 下一步 |
| --- | --- | --- |
| 键已发送但无变化 | 前台、模态框、控件焦点、程序忙碌 | 读窗口/焦点，等明确状态再用菜单入口 |
| 字母出现在正文里 | 菜单未打开或 chord 已超时 | 停止输入，确认意外改动后按任务需要恢复；改用命令面板 |
| Enter 后没有执行 | 输入法候选或建议列表 | 读取候选/字段状态，不自动第二次 Enter |
| Ctrl+Space 无效 | 中文输入法快捷键冲突 | 用应用菜单调用原动作；不擅改系统热键 |
| 标点组合触发错误 | OEM 键、键盘布局、Shift、主键区/小键盘 | 采用命名键并核对当前布局与应用显示的绑定 |
| sequence 中途停止 | 前台换窗、令牌/焦点保护、STOP | 看已完成笔数和当前菜单状态，重新观察后从正确状态继续 |
| 截图黑屏/文字不可读 | 最小化、受保护内容、捕获方式、缩放 | 使用结构化名称/值或恢复窗口；缺少目标证据就说明具体缺口 |
| 文件保存后仍不确定 | AutoSave、格式转换、只读、路径 | 检查标题/保存状态和目标文件；别重复覆盖作验证 |
| 发送无反馈 | 发件箱/气泡/传输状态、错误提示 | 先确认是否已提交，避免重复发送 |

## 验证一项本机快捷键

先从菜单、应用帮助或快捷键设置核对绑定与上下文，再在空白临时文档或可逆导航动作中验证。记录应用版本、语言、键盘布局、焦点、按键、预期变化和实际变化。聊天发送、数据库写入、ECO、运行代码和制造输出不作为快捷键探针。导航打开成功与用户业务目标完成分开记录。

官方默认值与本机实测是两类证据；本手册不会把文档核对写成已经在用户各应用中全部试过。

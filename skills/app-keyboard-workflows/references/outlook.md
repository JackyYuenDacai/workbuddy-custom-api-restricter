# Outlook 操作手册

先识别 **经典 Outlook Windows 桌面版**、**新版 Outlook** 或 **Outlook 网页版**。新版/网页的快捷键模式可设置为 Outlook、其他邮件服务或禁用；旧版全局组合键不能跨版本保证。先读 [Office 共通操作](office-common.md)。

## 经典 Windows Outlook

| 操作 | 默认键 | 核对点 |
| --- | --- | --- |
| 邮件/日历/联系人/任务模块 | `Ctrl+1/2/3/4` | 核对模块及当前账号 |
| 转到收件箱 | `Ctrl+Shift+I` | 核对是哪一个邮箱的 Inbox |
| 新邮件 | `Ctrl+Shift+M` | 不依当前模块；新窗口出现后重新观察 |
| 当前模块中新建 | `Ctrl+N` | 邮件、约会、联系人等依模块改变 |
| 搜索 | `Ctrl+E` / `F3` | 核对当前文件夹、邮箱或所有邮箱范围 |
| 打开所选项目 | `Enter` | 列表里是打开；撰写窗口是输入/提交其他控件 |
| 回复/全部回复/转发 | `Ctrl+R` / `Ctrl+Shift+R` / `Ctrl+F` | Ctrl+F 是转发，不是正文查找；核对收件人 |
| 标为已读/未读 | `Ctrl+Q` / `Ctrl+U` | 会修改邮件状态；文字编辑区域语义可能不同 |
| 移到文件夹 | `Ctrl+Shift+V` | 核对账号和目标文件夹；不是粘贴纯文本 |
| 删除所选项目 | `Delete` | 会移动到已删除等位置，不能当无害导航 |
| 日/工作周/周/月视图 | `Ctrl+Alt+1/2/3/4` | 日历模块内使用 |
| 新约会/会议请求 | `Ctrl+Shift+A` / `Ctrl+Shift+Q` | 会议有参与人和发送副作用；核对时区 |
| 拼写检查 | `F7` | 建议不自动接受 |
| 保存草稿 | `Ctrl+S` | 核对草稿文件夹/撰写窗口状态 |
| 发送 | `Alt+S` 或配置允许的 `Ctrl+Enter` | 最终动作，只在已有明确发送授权、目标和内容核对后执行一次 |

## 新版 Outlook / 网页版

| 目标 | Outlook 键位模式下常见键 | 验证要求 |
| --- | --- | --- |
| 新邮件/事件 | 新版桌面 `Ctrl+N`；网页版 Outlook 模式 `N` | 依当前模块；网页版 Ctrl+N 通常打开浏览器窗口，正文中 N 是输入文字 |
| 回复/全部回复 | `Ctrl+R` / `Ctrl+Shift+R` | 只在应用焦点正确时；网页 Ctrl+R 可能刷新 |
| 转发 | 新版桌面 `Ctrl+F`；网页版 `Ctrl+Shift+F` 或 `Shift+F` | 新版桌面与网页不能混用，先查本机快捷键帮助 |
| 发送 | `Ctrl+Enter` | 先核对快捷键模式与发送授权 |
| 关闭当前弹层 | `Esc` | 可能关闭搜索/撰写，检查草稿保存状态 |

新版/网页没有核实的导航键使用可访问性控件、菜单或设置中的键盘快捷键列表；不要为统一行为自动更改用户的快捷键模式。浏览器窗口中的 Alt+Left、Ctrl+W、Ctrl+L 保留浏览器意义。

## 不依赖图标的工作流

**找邮件**：确认账号/文件夹 → 搜索入口 → 输入发件人、主题或唯一短语 → 核对范围 → 从结果读取发件人、日期、主题 → 打开并核对正文。只出现同名主题不能证明是目标邮件。

**准备草稿**：新建 → 逐个确认 To/Cc/Bcc/Subject/正文焦点 → 输入 → 核对解析后的完整邮件地址及附件名称 → 保存草稿。不要用固定 Tab 次数从 To 跳正文，收件人建议列表会改变焦点。

**回复或发送**：选择正确邮件线程 → 回复类型 → 核对实际 To/Cc，尤其 Reply All → 完整内容与附件 → 根据用户已给的发送授权执行一次 → 核对 Sent Items/Outbox 和错误提示。排队在发件箱不等于送达；无反馈先检查，不重复发送。

**安排会议**：确认日历/账号 → 新会议 → 主题、参与人、时区、起止时间 → 查看忙闲和重复规则 → 按请求保存或发送邀请。不要把“创建日历草稿”扩展为通知所有参与者。

# 搜索、表格采集与分页

## 搜索和来源

保留用户指定的搜索引擎、浏览器及查询含义，正确编码查询词。先检查搜索结果是否被登录、同意页、验证码或网络错误替代。标题/摘要只能支持摘要层面的判断；需要正文事实时打开对应来源再读取。

优先读取当前可访问页面的结构化文本/表格；无 DOM 工具时只根据实际可见截图采集，不声称读到了隐藏行、折叠内容或离屏区域。不要尝试 DevTools、地址栏 javascript、读取浏览器数据库等替代未授权接口。

## 有界分页

1. 确定列名、记录数/页数范围和输出文件。用户要求大规模或“全部”但无已知边界时先说明范围/成本；范围不明确的小任务先整理当前页，不自行扩成整站抓取。
2. 每页记录可核实的来源 URL/标题、页面标记（页码或首尾记录）、采集时间和提取行数。URL 不可读时明确缺失，不从标题猜地址。
3. 选择稳定去重键（记录 ID/规范链接/用户同意的字段组合）；不要仅按姓名或标题合并不同记录。保留冲突值与来源，而不是后页静默覆盖前页。
4. 翻页前保存当前页结果；只点击可见且启用的下一页控件。等待并核对页码/首尾记录变化后才加入新结果。按钮存在不代表还有数据。
5. 当前范围完成、明确末页、重复页面指纹或下一页未变化时停止。虚拟列表同理：滚动成功不等于所有行都已加载；重复内容时不继续盲滚。

来源 URL 中有会话令牌或敏感参数时不直接写入公开报告，使用可分享链接或说明来源不可公开。不要采集用户任务之外的私人字段。

## 输出核对

先核对字段/单位与页面一致，再导出 Markdown/CSV/JSON 或已有表格工具。缺值留空/N/A；不把部分截图推测为完整表格。CSV/表格写入时把来自网页、以 =、+、-、@ 等开头的字符串作为文本处理，避免公式执行；保留真正数值的数值类型。

交付实际采集行数、原始行数/去重后行数、成功覆盖页数及未覆盖原因。网页提取不能证明数据真实性；需要事实核验时说明来源和不确定性。

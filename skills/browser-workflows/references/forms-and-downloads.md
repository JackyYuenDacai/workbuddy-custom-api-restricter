# 表单草稿与下载核对

## 表单

- 先识别站点/账号、字段标签、当前值、必填项以及是否自动保存。填写范围不明时不猜测联系方式、金额、权限或个人信息。
- 结构化工具用可见语义定位器；GUI 模式每次点击/替换/输入分别遵循 windows-computer-use 的新截图令牌和输入限制。不要猜测支持多行粘贴、上传或任意快捷键。
- 只修改授权字段，区分追加、替换和勾选；不要覆盖已有草稿。自动保存会产生外部写入，不能因为没点 Submit 就当作只读。
- 用户只要求“填写”时停在核对后的草稿。最终提交前展示目标及相关非敏感内容并取得所需确认；不要把 Enter 当作无副作用导航。
- 提交后核对回执、状态变化或校验错误。超时先只读检查是否已提交，不双击提交来确认。保存回执时不包含账号秘密。

## 下载

1. 用户授权下载后，确认来源、预期文件和保存位置。不要下载无关结果、运行下载内容、安装软件或解压到未知路径。
2. 有结构化下载事件时使用实际返回的文件句柄/路径；没有时观察浏览器下载 UI，并仅用已有且获授权的文件读取工具查看明确下载目录。不能假定可读取所有磁盘或自动更改浏览器下载设置。
3. 触发一次下载后核对进度。页面链接被点击不等于文件完成；超时/无反馈时先查看下载状态与目标目录，不能重复触发制造副本。
4. 核对确切文件名、完成状态、路径及合理大小；临时扩展名、大小为零、错误页面或仍在变化的文件不能直接视为成功。单独“大小稳定”不足以证明完整，优先结合浏览器完成状态/预期类型核对。
5. 遇到同名文件先说明并选择新文件名或获取覆盖授权。没有文件读取工具时仅报告浏览器可见状态，不编造本地路径、文件大小或哈希。

交付已验证文件及来源。若只能确认开始下载，明确“已触发，尚未验证完成”；不自动运行文件验证其是否可用。

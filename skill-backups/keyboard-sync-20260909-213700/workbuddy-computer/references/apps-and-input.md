# 应用、浏览器与文字输入

仅在相关任务中读取。工具名和约束按已安装的 local-computer-tools 实现核对，实际调用以当前发现的 schema 为准。

## 查找与启动

- 用户指定已有/正在运行的程序，或程序在登录后消失时，先按 [壳界面与恢复](recovery-and-shell.md) 查找现有窗口、任务栏分组与托盘；安装位置查找不能替代运行实例发现。尤其不要用重新启动来试探 QQ 等托盘应用是否已经登录。
- 打开新应用：`desktop_find_app(app)` → `desktop_launch(app, url?)`。当前支持 `firefox/chrome/edge/notepad`；查找覆盖注册表、常见目录和 PATH，PATH 未找到不等于未安装。
- QQ 等未在枚举内的程序不能传给这两个工具。用现有窗口/任务栏/托盘恢复；若实际缺少任意应用启动或进程查询能力，如实说明，不伪造 `qq` 参数或借终端重启绕过限制。进程存在只证明进程存在，不能证明有可操作窗口或已登录。
- `found=false` 只代表已检查位置未找到。不要全盘扫描、自动安装或把指定浏览器换成另一种；请用户提供安装位置或选择下一步。自定义路径也不能硬塞进枚举参数。
- 浏览器启动会开**新窗口**，保留已有窗口；不要把它当作导航已有窗口的工具。Notepad 不接受 URL，不接受任意 exe、命令或附加参数。
- URL 只允许 HTTP(S)，最长 2000，无内嵌账号密码、空格或控制字符。查询词必须 URL 编码；例如用户明确要求用 Firefox 在 Google 搜索 Astra 时，可启动 `https://www.google.com/search?q=Astra`。该请求不授权搜索结果里的下载或安装。
- 启动后只用返回的新窗口 ID 查 `desktop_browser_state(window_id)`。若没有新窗口 ID，先查 `desktop_windows`，不能猜 ID 或连续启动。

## 浏览器证据与已有窗口导航

`desktop_browser_state` 只读指定浏览器标题和可用地址栏，不读取网页表单、不改变焦点；URL 可能为空。根据结果决定是否需要激活并截图。

| 返回证据 | 能说明什么 |
| --- | --- |
| `process_started` | 进程启动调用成功，不证明新窗口或页面出现 |
| `window_observed` | 发现新窗口，不证明页面加载完成 |
| 标题 / URL 匹配 | 导航目标的辅助证据，不证明页面内容正确 |
| `page_verified=false` | 工具不验证页面；根据可见内容单独核对 |

出现网络错误、登录、验证码、同意页面时报告真实状态，不声称已获得结果。看到加载指示时做有限的只读复查，不通过反复导航催加载。仅要求“打开应用”时核对窗口即可，不读取额外私人内容。

导航用户指定的已有浏览器窗口：`desktop_focus` → `desktop_observe` → `desktop_key(CTRL+L)` → **新观察确认地址栏** → `desktop_type_text(url)` → **新观察确认地址** → `desktop_key(ENTER)` → 核对页面。每个输入动作分别使用新窗口 snapshot；Ctrl+L 仅用于支持的浏览器。打开新窗口并非用户意图时，不为少几次工具调用改用 launch。

## 输入、替换与提交

1. 新截图确认目标字段和当前内容。需要点击聚焦时，点击后重新观察，再输入；存在遮挡菜单、弹窗或不明焦点时先恢复。
2. 区分追加与替换。只在明确要替换的文本字段已聚焦且替换范围符合用户意图时用 Ctrl+A，再取新截图确认选区后输入。不能在未知焦点下全选/删除，也不能先清空再判断是否能输入目标文本。
3. `desktop_type_text` 输入 Unicode，不使用剪贴板、不自动按 Enter。当前 schema 长度上限 2000，并禁止换行、制表及其他控制字符。保留用户原文，不能静默截断、去掉换行或把多行拆成可能提交表单的一连串 Enter。
4. 长文、多行或富文本超出能力时，优先改用已有且获授权的文档/应用工具；没有合适工具就说明限制并让用户选择。不要虚构粘贴、文件上传、任意组合键或批处理接口。
5. 输入后核对可见文字、目标字段和错误提示；敏感字段交给用户，不截图确认秘密。后续 Enter/保存/发送是独立动作，按其副作用确认，重新观察后执行。

当前 `desktop_key` 枚举：`ENTER, TAB, ESC, BACKSPACE, DELETE, UP, DOWN, LEFT, RIGHT, HOME, END, PAGEUP, PAGEDOWN, CTRL+A, CTRL+F, CTRL+L, CTRL+S, CTRL+Z, CTRL+Y, SHIFT+TAB`。不要猜测支持 Ctrl+V、Alt+Tab、任意组合键或按住拖拽；使用当前 schema 确认能力。

输入超时可能只输入了部分文字，先观察字段再恢复。不能盲目重发整段、盲目 Ctrl+Z 或清空内容；已经提交但结果不确定时只读核对，停止重复提交。

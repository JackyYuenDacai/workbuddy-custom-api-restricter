## Windows 快捷操作与故障排查

本章用于跨应用焦点、窗口、菜单、输入法和按键工具。应用专用键见对应章节；窗口枚举、截图令牌、托盘发现沿用当前 computer-use 技能。

### 系统导航入口

| 目标 | Windows 常见键 | 使用条件与结果 |
| --- | --- | --- |
| 应用切换 | `Alt+Tab` / `Alt+Shift+Tab` | 窗口顺序会变，核对切换器/前台标题；不能盲数次数 |
| 任务视图 | `Win+Tab` | 可读标题选择目标，切换后重新观察 |
| 聚焦任务栏 | `Win+T` | 方向键选择，再读应用名/预览，Enter 激活 |
| 通知区域焦点 | `Win+B` | 方向键探索已显示图标；隐藏图标入口需确认后打开 |
| 按任务栏序号激活 | `Win+1`…`Win+9` | 仅已知排列时；可能启动新实例或选择组内窗口 |
| 显示桌面/恢复 | `Win+D` | 切换，会离开当前应用；不是关闭程序 |
| 窗口系统菜单 | `Alt+Space` | 读取移动/大小/最小化等项目，助记字母依语言 |
| 最大化/还原/最小化 | `Win+Up/Down` | Down 结果依初始状态；观察后再决定下一步 |
| 左右贴靠 | `Win+Left/Right` | 可能进入布局选择，核对窗口大小与内容可见性 |
| 移到另一显示器 | `Win+Shift+Left/Right` | 多显示器顺序以实际布局为准 |
| 关闭当前窗口 | `Alt+F4` | 可能关闭整个应用/弹保存提示；不用于恢复未知焦点 |
| 切换输入语言 | `Win+Space` | 读当前输入法；切换后再次核对，不假定一次到英文 |

系统组合键可能使前台离开目标窗口。WorkBuddy 的窗口约束若拒绝跨窗口动作，使用主技能提供的窗口选择接口；不要通过更换虚假的窗口 ID 绕过。动作完成后获取新目标状态/截图令牌。

托盘提示常在图标上方，也可在旁边；将 tooltip 名称与图标位置关联。展开隐藏图标后读取提示或可访问性名称，不从模糊形状猜程序。工具提供 hover 才能悬停；没有 hover 时使用可读名称或键盘焦点证据，不以点击未知图标代替识别。

### 按键表示与 WorkBuddy 参数

| 指南表示 | 键盘工具字段示例 | 含义 |
| --- | --- | --- |
| Ctrl+Shift+P | `key="CTRL+SHIFT+P"` | 同时修饰一个主键，自动释放 |
| Ctrl+K → Ctrl+S | `sequence=["CTRL+K","CTRL+S"]` | 两笔 chord，各笔之间释放 |
| Ctrl+K → Z | `sequence=["CTRL+K","Z"]` | 第二笔不带 Ctrl |
| P → W | `sequence=["P","W"]` | 仅菜单路径已确认时，字母依次按；不是输入字符串 |
| Ctrl+加号 | `key="CTRL+PLUS"` | 主键区加号，隐含相应 Shift；数字小键盘是 ADD |
| Alt+等号 | `key="ALT+EQUAL"` | 不加 Shift，常见 Excel 自动求和 |
| Shift+F10 | `key="SHIFT+F10"` | 当前控件的上下文菜单 |

表格中的 `Ctrl+B/I/U` 是三个可选组合键的简写，必须展开为 `CTRL+B`、`CTRL+I` 或 `CTRL+U`；`Left/Right` 同理。不能把斜杠或箭头原样传给工具。

`local-computer-tools` 0.6.0 支持 Ctrl/Alt/Shift/Win 与左右修饰键、字母、数字、F1–F24、导航、数字小键盘、标点、多媒体和 `VK_0xNN`（08–FE）。罕见 VK 需先核实语义，不代表所有应用都实现该快捷键。Fn 通常由硬件处理，Ctrl+Alt+Delete、安全桌面/UAC 不是普通 SendInput 可保证的范围。

一次调用仅传 key 或 sequence 之一；sequence 为 1–8 笔的一项已知快捷操作，不用它拼接搜索、输入、发送等多阶段宏。工具仍需有效窗口与新截图令牌，并检查焦点、敏感控件和 STOP。实际完整字段以当前 MCP schema 为准；上表只展示按键字段。运行中若仍看到旧 enum，重新连接 MCP 后发现 schema。

文本用 Unicode 输入工具，按键用键盘工具。当前文字工具每次最多 2000 字符且不接收换行/控制字符；多段文字按应用已确认的换行方式连接，再核对完整内容。不要用数字 VK 枚举来代替任意 Unicode 文本。

### 故障诊断表

| 症状 | 先检查 | 下一步 |
| --- | --- | --- |
| 键已发送但无变化 | 前台、模态框、控件焦点、程序忙碌 | 读窗口/焦点，等明确状态再用菜单入口 |
| 字母出现在正文里 | 菜单未打开或 chord 已超时 | 停止输入，确认意外改动后按任务需要恢复；改用命令面板 |
| Enter 后没有执行 | 输入法候选或建议列表 | 读取候选/字段状态，不自动第二次 Enter |
| Ctrl+Space 无效 | 中文输入法快捷键冲突 | 用应用菜单调用原动作；不擅改系统热键 |
| 标点组合触发错误 | OEM 键、键盘布局、Shift、主键区/小键盘 | 采用命名键并核对当前布局与应用显示的绑定 |
| sequence 中途停止 | 前台换窗、令牌/焦点保护、STOP | 看已完成笔数和当前菜单状态，重新观察后从正确状态继续 |
| 截图黑屏/文字不可读 | 最小化、受保护内容、捕获方式、缩放 | 使用结构化名称/值或恢复窗口；缺少目标证据就说明具体缺口 |
| 文件保存后仍不确定 | AutoSave、格式转换、只读、路径 | 检查标题/保存状态和目标文件；别重复覆盖作验证 |
| 发送无反馈 | 发件箱/气泡/传输状态、错误提示 | 先确认是否已提交，避免重复发送 |

### 验证一项本机快捷键

先从菜单、应用帮助或快捷键设置核对绑定与上下文，再在空白临时文档或可逆导航动作中验证。记录应用版本、语言、键盘布局、焦点、按键、预期变化和实际变化。聊天发送、数据库写入、ECO、运行代码和制造输出不作为快捷键探针。导航打开成功与用户业务目标完成分开记录。

官方默认值与本机实测是两类证据；本手册不会把文档核对写成已经在用户各应用中全部试过。

## Office 共通操作：Windows 桌面版

本章适用于 Microsoft 365 / Office Windows 桌面应用。网页 Office、Mac、WPS、LibreOffice 不保证同键；远程桌面可能截获系统键。Outlook 先区分经典版与新版。应用自定义绑定、语言、输入法、插件优先于默认表。

### 图标不清时的入口

| 目标 | 默认键 | 正确使用 |
| --- | --- | --- |
| 显示 Ribbon KeyTips | `Alt` 或 `F10` | 先释放，读取当前屏幕上字母；再依次选标签和命令，不把整个路径同时按住 |
| 搜索应用命令 | `Alt+Q` | 支持的现代 Office 中进入 Search/Tell Me；确认是应用命令搜索，不是文档查找 |
| 窗格循环 | `F6` / `Shift+F6` | 正文/工作表、Ribbon、状态栏、任务窗格等；次序随布局变化 |
| 当前控件组导航 | `Tab` / `Shift+Tab`、方向键 | 核对焦点框/控件名称，不按固定 Tab 次数 |
| 上下文菜单 | `Shift+F10` / `APPS` | 根据当前文字、单元格、对象或列表选择打开 |
| Ribbon 折叠/展开 | `Ctrl+F1` | 切换状态；勿在未知状态重复按 |
| 关闭当前弹层 | `Esc` | 一层一次；可能取消编辑，不是通用退出全部操作 |
| 帮助 | `F1` | 可能打开帮助任务窗格/网页；不等于业务操作完成 |

**KeyTips 流程**：确认应用与文档 → Alt → 新观察读取标签字母 → 按字母 → 新观察读取命令字母 → 选择 → 核对对话框/结果。英文版常见 File/Home/Insert/Review/View 字母为 F/H/N/R/W，但不要把它们当作跨语言保证。若某版支持 `Alt+Q`，可以直接搜索“另存为”“插入表格”“选择窗格”等本地化命令；选择前核对具体命令，搜索结果可能含帮助条目。

`sequence` 适合已经核实且仍在同一窗口的一项短快捷操作；KeyTips 未确认、菜单需等待、弹窗更换前台窗口时拆开操作。序列中断后检查已打开的菜单，不重发完整链。

### 文档、剪贴板和保存

| 目标 | 常见键 | 边界 |
| --- | --- | --- |
| 打开 | `Ctrl+O` | 可能先进入 Backstage；核对本地/云端路径 |
| 新建 | `Ctrl+N` | 新文档/工作簿/演示文稿；Outlook 依当前模块，新建对象可能不同 |
| 保存 | `Ctrl+S` | 初次保存可能出现对话框；Access 数据记录与对象设计另有语义 |
| 另存为 | `F12`（Word/Excel/PowerPoint 桌面版） | 核对路径、格式和覆盖提示；其他应用不套用 |
| 打印入口 | `Ctrl+P` | 打开预览不等于已经打印；核对打印机、范围、份数后才最终打印 |
| 关闭当前文档 | `Ctrl+F4` | 可能有未保存提示；不默认丢弃 |
| 复制/剪切/粘贴 | `Ctrl+C/X/V` | 先确认选区和剪贴板来源；V 可能携带格式、公式或链接 |
| 撤销 | `Ctrl+Z` | 只撤销明确属于当前任务的最近操作；云协作和数据库提交不保证可撤销 |
| 重做/重复 | `Ctrl+Y` | 不总是重做；可能重复最近动作 |

保存对话框中可用 `Ctrl+L` / `Alt+D` 聚焦路径栏（以当前对话框为准），但**不是所有 Office 正文的地址栏快捷键**。确认“文件名”控件后输入文件名，明确选择格式，再执行保存。观察文档标题/保存状态；有文件工具时验证目标文件存在、扩展名正确。不要仅因对话框消失就宣称文件格式正确。

AutoSave 打开时，修改可能立即同步；Ctrl+S 不是唯一写入时点。受保护视图、只读、共享权限、密码或 UAC 不能靠快捷键绕过，也不要为使快捷键成功自动启用宏。

### 键名、布局与多行

`Ctrl+Shift+>` 是字符表示；美式键盘常用工具参数 `CTRL+SHIFT+PERIOD`。`Ctrl+;` 为 `CTRL+SEMICOLON`，`Ctrl+Shift+:` 对应 `CTRL+SHIFT+SEMICOLON`；`Ctrl+~` 对应 `CTRL+SHIFT+BACKTICK`。其他布局用应用菜单核对，不能假设字符=同一物理键。

Ctrl 加主键区加号用 `CTRL+PLUS` / `CTRL++`；数字小键盘加号是 `CTRL+ADD`。`NUMPAD_ENTER`、`NUMPAD0`…`NUMPAD9` 与主键区数字/Enter 不同。公式和文字用 Unicode 输入工具；快捷键工具不是任意文本输入器。

换行需读对应应用：Word Enter 新段落、Shift+Enter 软换行；Excel Alt+Enter 单元格内换行；Outlook Ctrl+Enter 可能发送邮件。不能跨应用照搬。

### 完成检查

导航：文档身份 + 实际目标位置。编辑：目标选区 + 内容/公式/对象属性。保存：路径/格式 + 保存状态。打印/发送/发布：按用户已有授权执行一次，再核对输出状态；失败/超时不自动重复最终动作。

Microsoft 来源及版本说明见各应用章节。指南覆盖常用完整工作流，不保证每个历史版本、插件或自定义功能的所有键位。

## Word 操作手册

先读 [Office 共通操作](#office-common)。适用于 Windows 桌面 Word；区分正文、导航窗格、表格、页眉页脚、批注编辑框和对话框。

### 阅读、定位和选择

| 操作 | 默认键 | 核对 |
| --- | --- | --- |
| 导航/查找 | `Ctrl+F` | 输入关键词，检查结果和当前位置 |
| 替换 | `Ctrl+H` | 先检查查找条件、格式和范围；不默认全部替换 |
| 转到页/节/书签等 | `Ctrl+G` / `F5` | 确认 Go To 类型，再输入目标 |
| 文档首/尾 | `Ctrl+Home` / `Ctrl+End` | 正文焦点；窗格中可能是列表首尾 |
| 上/下单词 | `Ctrl+Left` / `Ctrl+Right` | 编辑光标移动 |
| 上/下段落 | `Ctrl+Up` / `Ctrl+Down` | 核对目标段落 |
| 扩展字符/单词选区 | `Shift+方向键` / `Ctrl+Shift+Left/Right` | 核对选区首尾 |
| 选到行首/行尾 | `Shift+Home` / `Shift+End` | 视觉行，不一定完整段落 |
| 扩展到文档首/尾 | `Ctrl+Shift+Home/End` | 很大选区；修改前核对 |
| 全选 | `Ctrl+A` | 焦点在正文或当前字段，作用域不同 |
| 返回上次编辑位置 | `Shift+F5` | 核对实际定位，不假定与上次阅读位置相同 |

### 样式和排版

| 操作 | 默认键 | 注意 |
| --- | --- | --- |
| 粗体/斜体/下划线 | `Ctrl+B/I/U` | 切换；无选区时影响后续输入 |
| 字体对话框 | `Ctrl+D` | 用数值和控件名称核对字体/字号 |
| 字号增/减 1 磅 | `Ctrl+]` / `Ctrl+[` | 工具为 RBRACKET/LBRACKET |
| 居中/左/右/两端对齐 | `Ctrl+E/L/R/J` | 段落级，不是整页布局 |
| 单倍/双倍/1.5 倍行距 | `Ctrl+1/2/5` | 当前段落或选中段落 |
| 增/减段落缩进 | `Ctrl+M` / `Ctrl+Shift+M` | 不用空格模拟缩进 |
| 悬挂缩进/减小 | `Ctrl+T` / `Ctrl+Shift+T` | 核对标尺/段落设置 |
| 正文样式 | `Ctrl+Shift+N` | 应用 Normal，不保证删除所有直接格式 |
| 标题 1/2/3 | `Ctrl+Alt+1/2/3` | 优先真实标题样式，便于导航和目录 |
| 应用样式入口 | `Ctrl+Shift+S` | 样式名称依本地化和模板 |
| 显示格式标记 | `Ctrl+Shift+8` | ¶ 显示/隐藏；不是插入段落符 |
| 清除直接字符格式 | `Ctrl+Space` | 中文环境可能被输入法占用；改用命令搜索 |
| 清除直接段落格式 | `Ctrl+Q` | 不当作退出程序 |
| 切换大小写 | `Shift+F3` | 核对所选文字，中文一般不受影响 |

### 插入、表格和审阅

| 操作 | 默认键 | 注意 |
| --- | --- | --- |
| 新段落/软换行 | `Enter` / `Shift+Enter` | 两者有不同段落样式与间距结果 |
| 分页符 | `Ctrl+Enter` | 不用多次 Enter 撑到下一页 |
| 超链接 | `Ctrl+K` | 核对显示文本和链接地址 |
| 脚注/尾注 | `Ctrl+Alt+F` / `Ctrl+Alt+D` | 依模板编号，核对位置 |
| 表格下/上一格 | `Tab` / `Shift+Tab` | 最后一格的 Tab 会新增一行 |
| 表格内插入制表符 | `Ctrl+Tab` | 不离开单元格 |
| 拼写/编辑器 | `F7` | 当前版本可能显示 Editor；建议不是自动接受 |
| 插入批注 | `Ctrl+Alt+M` | 某些现代批注需要 Post；创建编辑框≠已发布 |
| 修订开/关 | `Ctrl+Shift+E` | 先确认当前状态与用户意图，别无意关闭审阅 |
| 更新所选域 | `F9` | 链接、目录和域可能变化；核对提示与结果 |
| 域代码/结果切换 | `Alt+F9` | 改显示模式，不等于刷新数据 |

Microsoft 365 新版中 `Ctrl+Shift+V` 通常是“仅粘贴文本”；旧版曾用于粘贴格式，不能按旧经验操作。Paste Special/Format Painter 用菜单或命令搜索确认当前绑定。

### 工作流

**修改特定段落**：Ctrl+F 搜索唯一片段 → 核对页码/前后文 → 回到正文并准确选择 → 输入替换 → 核对内容及样式 → 按请求保存。查找框仍有焦点时 Ctrl+A 只会选搜索词。

**制作结构化文档**：输入标题/正文 → 用标题样式分级 → 插入真正分页符和表格 → 命令搜索插入目录 → 更新并查看分页 → 保存。不要用一串空格、Tab 和空段落模仿布局。

**审阅并保留修订**：确认文档/修订状态 → 开启或保留 Track Changes → 编辑 → 按需批注 → 阅读审阅窗格 → 保存；不自动接受所有修订。

**导出 PDF**：保存原稿 → F12 或命令搜索另存为/导出 → 核对 PDF 类型、路径及范围 → 执行 → 用可用文件/预览工具核对页数、分页、表格和文字。快捷键完成保存不证明视觉排版正确。

来源：[Microsoft Word shortcuts](https://support.microsoft.com/en-us/accessibility/word/keyboard-shortcuts-in-word)，2026-09-09 查阅 Windows 相关内容。未在用户实际文档试键。

### 工作流与易错点

**准确修改 D12**：Ctrl+G → D12 → 确认名称框与原值 → 要改局部则 F2，要替换整格才直接输入 → Enter → 重新定位并核对公式栏/值 → 保存。

**填充公式**：确认首格公式 → Ctrl+G 选择完整目标区域 → Ctrl+D 或 Ctrl+R → 核对起点、中间、末端的相对/绝对引用和结果。先检查合并单元格、筛选、表格计算列是否改变行为。

**排序/筛选**：识别整个表和标题 → 打开筛选或排序入口 → 读取字段/顺序/范围 → 核对完整行仍对应。不要只排序一列而破坏记录；出现“扩展选定区域”先判断数据结构。

**导出**：先保存工作簿 → 另存为核对格式；CSV 可能仅导出活动表并丢失公式/格式/多表信息，必须符合用户目标。PDF 先核对打印区域、缩放和分页。

方向键只滚动不换活动格时检查 Scroll Lock；不要连续按键试探。`####` 可能是列宽或日期显示问题，不等于数据丢失。公式作为文字时检查前导单引号、文本格式和公式显示模式。受保护表不能通过解除保护绕过用户权限。

| --- | --- | --- |
| 新邮件/事件 | 新版桌面 `Ctrl+N`；网页版 Outlook 模式 `N` | 依当前模块；网页版 Ctrl+N 通常打开浏览器窗口，正文中 N 是输入文字 |

### 不依赖图标的工作流

**准备草稿**：新建 → 逐个确认 To/Cc/Bcc/Subject/正文焦点 → 输入 → 核对解析后的完整邮件地址及附件名称 → 保存草稿。不要用固定 Tab 次数从 To 跳正文，收件人建议列表会改变焦点。

**安排会议**：确认日历/账号 → 新会议 → 主题、参与人、时区、起止时间 → 查看忙闲和重复规则 → 按请求保存或发送邀请。不要把“创建日历草稿”扩展为通知所有参与者。

**整理会议笔记**：选择正确笔记本/分区 → Ctrl+N → 核对标题焦点并输入标题 → 正文建立标题/段落/待办 → 检查容器顺序 → 核对同步状态。Ctrl+A 的范围可能逐层扩展，不先确认就删除会影响更多笔记。

**找笔记并更新待办**：全局搜索关键词 → 核对笔记本、分区、页标题和日期 → 定位任务段落 → 检查原勾选状态 → 切换一次 → 核对。反复 Ctrl+1 不保证得到“已完成”。

OneNote 通常自动保存；另存为快捷键不能套用 Word 的 F12。分享笔记本、改权限、导出和发送页面另按用户需求处理。输入 Ctrl+Shift+M 等历史 Quick Note 热键前，先核对当前版本，避免创建与目标无关的笔记。

来源：[Microsoft OneNote shortcuts](https://support.microsoft.com/en-us/accessibility/onenote/keyboard-shortcuts-in-onenote)，2026-09-09 查阅；部分同页快捷键依版本不同，未验证的配置以本机帮助为准。

## Access 操作手册

适用于 Windows 桌面 Access，先读 [Office 共通操作](#office-common)。区分数据库文件、导航窗格中的对象、Datasheet 数据记录、Form 表单、Design 设计视图、Query 查询及属性字段。

**数据库与普通文档不同：离开记录可能自动提交数据，Ctrl+S 经常保存对象设计；不能认为“不按保存”就不会改数据库。** 删除/更新查询可能批量修改数据，不能靠输入宏或盲目撤销试验。

| 操作 | 默认键 | 核对点 |
| --- | --- | --- |
| 导航窗格显隐 | `F11` | 查看对象列表，不是全屏 |
| 属性表显隐 | `F4` | 当前对象/控件属性 |
| 切换窗格 | `F6` / `Shift+F6` | 设计网格、属性、导航等随上下文变化 |

| 打开所选对象 | `Enter` | 导航窗格中，表单/查询可能有加载事件或提示 |

| 查找/替换 | `Ctrl+F/H` | 检查对象、字段、匹配方式；替换会改记录 |
| 当前字段扩大编辑窗口 | `Shift+F2` | Zoom 对话框便于读取长文本；不等于缩放设计画布 |
| 编辑/导航模式切换 | `F2` | Datasheet 中；导航窗格 F2 可能重命名对象 |

| 当前记录首/末字段 | `Home` / `End` | 非字段文字编辑模式；核对活动格 |
| 首/末记录 | `Ctrl+Home` / `Ctrl+End` | 导航模式中，选定记录并非排序后的业务“最新” |
| 添加新记录 | `Ctrl+PLUS` | 当前允许新增的记录视图；不是普通放大 |
| 保存当前记录修改 | `Shift+Enter` | 明确提交，核对校验/约束提示 |

| 插入当前日期 | `Ctrl+SEMICOLON` | 日期格式由区域/字段类型决定 |
| 数据字段内换行 | `Ctrl+Enter` | 只在支持多行的文本字段；注意导航窗格中的不同意义 |
| 保存对象设计 | `Ctrl+S` | 核对是表、查询、表单等对象，不当成记录提交统一键 |
| 关闭活动对象 | `Ctrl+F4` | 可能出现设计保存或数据验证提示 |

**只读检查**：确认数据库和目标对象 → 导航窗格定位 → 打开合适视图 → 查找记录 → 阅读字段/主键 → 不进入编辑或执行动作查询。查询运行是否只读要看具体 SQL/类型，不能凭名称猜测。

**修改一条记录**：核对主键和原值 → 确定字段 → F2 或 Zoom 编辑 → 核对新值 → 按已有授权提交 → 再次定位主键验证。出现关系约束/重复键错误，先解释原因，不换主键或关闭校验来绕过。

**设计更改**：先明确对象和备份/版本需求 → 设计视图 → 修改指定属性 → 核对影响 → 保存。不要将可见界面的字段删除理解为仅删除显示内容；表结构修改可能影响数据与其他对象。

| 清除历史对话框 | `Ctrl+Shift+Delete` | 仅打开入口；不要默认清除全部数据 |

下载、打印、保存页面和书签对话框可能成为独立窗口。不要用一个 `sequence` 连续切窗口并确认路径；每次核对新窗口和文件名。地址栏建议可以包含历史、书签和远程搜索，Enter 前检查最终字符串与候选，不仅检查输入的关键词。

**内置 PDF**：先确认 Firefox PDF 阅读器。页面查找、缩放与打印可能由阅读器处理；优先读取工具栏的页码、总页数、缩放框和下载控件名称。PDF 扫描图没有可搜索文本时，零匹配不等于内容不存在。不要把普通网页 Home/End 的结果当成 PDF 页号定位成功。

**表单**：Tab 导航到字段 → 读取标签/当前值 → 编辑 → 验证值与验证错误。Space 在复选框切换勾选；箭头在单选组或下拉项改变选项。输入法候选仍显示时 Enter 可能只提交候选词。表单发送由明确的目标按钮及已有用户授权决定，不靠连续 Enter 猜测。

### 可靠工作流

**导航已有窗口**：确认 Firefox → Ctrl+L → 确认地址栏焦点 → 输入用户指定地址 → 确认文字 → Enter → 核对 URL、标题及目标页面内容。地址相同但显示登录或错误页，不能报告页面任务完成。

**链接太小**：Ctrl+F 搜索已知可见文字 → 核对命中 → 用可访问性链接节点或新截图点击目标；不要假定 Enter 在查找栏里会打开链接。若只有图形按钮，页面缩放可以辅助观察，但不能创造不存在的控件语义。

**恢复页内焦点**：Esc 关闭已确认的查找/菜单 → 用 F6 或 Tab 切到页面并检查焦点；不要用固定 Tab 次数定位付款、发送或删除按钮。空格在网页可能滚动、勾选复选框或激活控件，Enter 可能提交表单。

来源入口：Mozilla [Keyboard shortcuts](https://support.mozilla.org/en-US/kb/keyboard-shortcuts-perform-firefox-tasks-quickly)。2026-09-09 该站返回浏览器验证页，未把该响应当作文档核验；上表为常见默认值，执行时以本机菜单为准。


<a id="qq"></a>

## QQ / QQNT — Windows

QQ 经典版与新版 QQNT 的全局热键、搜索和发送键可以不同，还可能被微信、截图工具或输入法占用。不能把下面的经典默认候选当作已验证的本机设置。第一次需要某项热键时，在 QQ 设置的“快捷键/热键”与聊天输入框“发送”旁的选项中核对，并记录当前会话有效的绑定；不要改用户的发送习惯。

### 常用入口和按键

| 目标 | 按键/入口 | 适用性与结果核对 |
| --- | --- | --- |
| 恢复现有 QQ | 主技能的窗口 ID、任务栏、系统托盘流程 | 窗口列表缺失不等于退出；先查隐藏图标，不直接启动第二实例 |
| 提取/打开消息 | `Ctrl+Alt+Z` | 经典版常见默认，可更改/禁用；可能跳到未读联系人，不保证目标聊天 |
| 截图 | `Ctrl+Alt+A` | 常见可配置全局热键；可能打开 QQ 或别的软件截图层，不能作为“查 QQ 在不在”的探测 |
| 搜索联系人/群 | 主窗口搜索框；仅在当前版本明确显示时用其搜索快捷键 | 不假定 Ctrl+F 一定是联系人搜索；确认搜索范围再输入姓名/号码 |
| 搜索当前聊天 | 当前会话中的“聊天记录/搜索”入口 | QQNT/经典版入口和绑定不同；Ctrl+F 仅在菜单/设置确认后使用 |
| 列表选择 | `Up` / `Down` | 先确认焦点在搜索结果/联系人列表，核对选中项身份 |
| 打开所选联系人 | `Enter` | 只在已确认结果列表焦点时；聊天输入框里的同一键可能发送 |
| 字段切换 | `Tab` / `Shift+Tab` | 逐步核对控件，不用固定 Tab 次数猜输入框 |
| 关闭已知弹层 | `Esc` | 先判断是否截图层、搜索、候选窗或聊天窗口；不盲目重复 |
| 文本全选/修改 | `Ctrl+A`、方向键、Backspace | 仅在已确认的消息编辑框中；消息列表全选可能是另一操作 |
| 发送消息 | `Enter` 或 `Ctrl+Enter` | 以“发送”按钮选项的当前设置为准；执行前核对联系人、完整内容与已有发送授权 |
| 换行 | 当前发送模式对应的换行方式，常见为 `Ctrl+Enter` 或 `Enter` | 不能拿真实消息试验哪一个会发送；Shift+Enter 也不能跨版本保证 |

**特别注意**：文字输入工具仍拒绝换行/控制字符，但 0.6.0 的键盘工具支持 `CTRL+ENTER` / `SHIFT+ENTER`。已从设置确认哪一键换行后，可以分段输入并用该换行键连接，每次观察核对。若发送模式未知，先查设置，不能拿真实消息试键，不偷偷改成一行或分多次发送。

### 恢复、搜索、撰写

1. 根据 QQ 标题/进程找到当前窗口；托盘恢复时读取已出现的 tooltip，常在图标上方，也可能在旁边。把提示文字与当前图标关联；不点击 tooltip 本身。仅当工具支持 hover 时才用悬停产生提示；不要拿未知图标点击代替悬停。
2. 激活后确认账号和目标联系人/群。昵称重名时结合 QQ 号、群名或用户提供的身份；不会因为“打开了一个聊天”就认为目标正确。
3. 从主窗口搜索定位联系人，核对结果，再打开。进入会话后确认聊天标题，随后聚焦输入框。
4. 写入草稿后核对全文。用户只要求准备/编辑时保留草稿；用户已明确要求向该联系人发送这些内容时，不重复索取同一授权，核对当前发送键后执行一次。
5. 查看消息气泡及发送状态；超时或界面无反馈时先核对是否已经发送，不重发来验证。登录、验证码或密码由用户处理。

### 本机热键登记与更完整的任务路线

QQ 的“完整指南”应包含确认键位的办法，而不是把经典版候选填成 QQNT 保证可用的表。第一次查看设置时按以下字段记录在当前会话；不修改原设置：

| 项目 | 需要读取的实际值 | 执行后的证据 |
| --- | --- | --- |
| 版本/账号 | QQNT 或经典版、版本号、当前账号 | 设置/主窗口身份 |
| 提取消息热键 | 当前组合键、是否启用、是否冲突 | 恢复后的聊天标题；可能是最新未读而非目标 |
| 截图热键 | 组合键及工具归属 | 截图层的品牌、按钮/提示 |
| 发送方式 | Enter 发送或 Ctrl+Enter 发送 | 发送按钮选项中的选中状态 |
| 换行方式 | 与当前发送方式相配的实际绑定 | 以设置说明为准，不用真实消息试验 |
| 搜索范围 | 联系人/群/当前聊天/全局消息 | 搜索栏标签、搜索结果分类 |
| 关闭窗口行为 | 关闭窗口或最小化到托盘 | 窗口/托盘状态，不以任务栏消失判定退出 |

**查聊天记录**：从正确聊天进入记录搜索 → 指定关键词/日期/文件类型 → 核对发送人、时间和前后消息 → 回到原会话核对标题。全局搜索同名结果与当前聊天记录不是同一范围。

**准备多段消息**：先读取发送/换行设置 → 聚焦正确聊天输入框 → 分段输入与已确认的换行键 → 检查完整草稿与附件 → 根据请求保存草稿或发送一次。输入工具每次最多 2000 字符时按段分次输入；切分不能偷偷改变消息边界或发送次数。

**发送文件**：进入目标聊天 → 通过已识别的“文件”入口打开选择器 → 核对路径、文件名、类型与实际附件预览 → 按已有发送授权提交 → 核对传输完成/失败状态。`Ctrl+V` 若剪贴板是文件或图片，可能形成附件或发送预览；不要把它当作保证只粘贴文字。

**截图**：任务确需截图时才使用已核实热键 → 核对截图层 → 选择区域并检查预览 → 区分复制、保存、取消、发送。截图完成不自动授权发给当前聊天。

**修改草稿**：确认输入框焦点 → Ctrl+Home/End、Ctrl+Left/Right 和加 Shift 的选择键可用于标准文本编辑；富文本控件、表情块和引用消息可能改变光标行为，按结果核对。Ctrl+A 后先确认仅选中草稿再替换。

**托盘找不到**：按主技能检查任务栏和隐藏图标；若提示显示在图标上方/旁边，读取名称并关联其指向的图标。QQ 可能正在登录、后台运行或有独立会话窗口；先恢复已有实例，不反复启动。需要菜单时在已识别图标上打开上下文菜单并读项目。

**无响应恢复**：先查模态文件选择器、截图层、输入法候选、快捷键冲突和焦点。已确认弹层用一次 Esc 退出后重新观察。聊天发送结果不明时先读消息气泡/失败标记；禁止用第二次发送作为验证。

### 来源与置信度

QQ 没有在本次核验中取得覆盖经典版和 QQNT 的统一官方键位表，也没有读取用户聊天内容来测试。`Ctrl+Alt+Z` 与 `Ctrl+Alt+A` 仅作为经典常见绑定候选；本机设置、菜单提示及发送方式选项是最终依据。不要编造未经确认的“快速打开联系人”组合键。

## Altium Designer — Windows

快捷键取决于编辑器与当前交互命令。先识别活动文档：`.SchDoc/.SchLib` 原理图/符号，`.PcbDoc/.PcbLib` PCB/封装；再看画布、面板、属性字段、菜单或对话框谁有焦点。中文输入法组合状态会影响字母助记键。

### 跨编辑器的入口

| 目标 | 默认键 | 核对点 |
| --- | --- | --- |
| 打开已有文档 | `Ctrl+O` | 在 Open 对话框确认完整路径与文档类型 |
| 保存当前文档 | `Ctrl+S` | 核对文档名和未保存标记，不等于保存所有项目文档 |
| 关闭当前文档 | `Ctrl+F4` | 处理保存提示；不要用 Ctrl+W 代替 |
| 面板/设计文档间切换焦点 | `Shift+F5` | 最后活动面板与当前设计文档之间切换；核对焦点 |
| 浮动面板显隐 | `F4` | 是切换，不保证所有停靠面板都消失 |
| 上/下一个已激活文档 | `Alt+Left` / `Alt+Right` | 按激活历史，确认文件标题 |
| 当前交互阶段快捷键菜单 | `Shift+F1` | 在正在放置、移动或布线时查看；Esc 关闭帮助菜单后仍可能处于原命令 |
| 上下文帮助 | `F1` | 依资源/交互模式显示帮助；不等于执行帮助条目 |
| 取消当前交互阶段 | `Esc` | 一次可能只取消当前线段/对象；观察状态栏、光标和附着对象，再决定是否需下一次 Esc |

### 原理图 / Schematic

| 目标 | 默认键 | 适用模式/核对点 |
| --- | --- | --- |
| 显示全部设计对象 | `Ctrl+PageDown` | 画布焦点且没有未结束的放置动作；核对图纸对象范围 |
| 缩放 | `PageUp` / `PageDown` | 以当前光标位置为中心；光标位置未知时优先显示全部 |
| 重绘屏幕 | `End` | 用于画面刷新，不修改设计 |
| 清除当前过滤 | `Shift+C` | 原理图过滤；核对先前隐藏/变暗对象恢复 |
| 切换预设捕捉网格 | `G` / `Shift+G` | 向前/向后切换，核对状态栏网格值；不要为视觉方便乱改精度 |
| 进入画线 | `Ctrl+W` | **不是关闭标签**；进入后核对 Wire 模式，未确定连接点就不落点 |
| 测量两点距离 | `Ctrl+M` | 进入测量，不会自动选择两点；核对坐标与单位 |
| 放置/移动时编辑属性 | `Tab` | 暂停交互并进入 Properties；再按 Tab 可能只是字段切换 |
| 旋转附着对象 | `Space` / `Shift+Space` | 对象放置/移动时逆/顺时针 90°；画线时同键有不同作用 |
| 镜像附着对象 | `X` / `Y` | 仅已确认对象处于放置/移动模式；不是全局镜像命令 |
| 画线时切换起止子模式 | `Space` | Wire/Bus 等交互状态；核对预览 |
| 画线时切换拐角模式 | `Shift+Space` | 与旋转对象不同；以 Shift+F1 当前帮助为准 |

常见菜单序列 `P → W` 表示 Place → Wire。只在当前菜单明确显示相应助记字母时执行；本地化或自定义菜单可能不同。先 P 打开菜单，再核对 Wire，最后 W；不要把字母输入属性字段。

### PCB / Footprint

以下查看键仅在**普通画布浏览模式**、没有布线/长度调节/放置命令时使用。

| 目标 | 默认键 | 适用模式/核对点 |
| --- | --- | --- |
| 2D / 3D 布局视图 | 顶行 `2` / `3` | 核对视图模式；数字小键盘的 2/3 在 3D 中另有用途 |
| 显示全部设计对象 | `Ctrl+PageDown` | 核对板与对象范围 |
| 缩放/重绘 | `PageUp` / `PageDown`；`End` | 光标相关缩放；End 重绘 |
| 单层显示模式循环 | `Shift+S` | 核对层显示；不是删层 |
| 视图配置 | `L` | 普通查看时进入 View Configuration；布线中的 L 可能切换布线层 |
| 网格菜单 | `G` | 是菜单，区别于原理图的直接循环网格 |
| 翻转板视图 | `Ctrl+F` | **不是文本查找**；可能把板/元件视图翻到另一面 |
| 清除过滤 | `Shift+C` | 普通 2D 浏览时使用；3D 可清测量，布线状态可切换 subnet swapping，不能通用恢复 |
| 查看当前交互快捷键 | `Shift+F1` | 布线/滑动/长度调节时优先看当前命令帮助 |
| 交互时属性 | `Tab` | 进入相应 Properties 模式；普通 PCB 选择状态的 Tab 可能扩展选区 |

常见 PCB 菜单序列 `P → T`（Place → Track）或 `R → I`（Route → Interactive Routing）依当前版本菜单核实再用。`Space`、`Shift+Space`、数字键及 L 在布线、长度调节、3D 各有含义；不能从普通浏览表推断交互动作。

### 模式决策表：先判断再按键

| 当前状态 | 可用入口 | 容易误用的键 |
| --- | --- | --- |
| 原理图普通画布 | Ctrl+PageDown、Projects/SCH 面板、菜单查找 | Ctrl+W 进入画线；不是关闭 |
| 原理图附着元件 | Tab 属性、Shift+F1 当前帮助 | Space 旋转；X/Y 镜像；Enter 可能落点 |
| 原理图画线 | Shift+F1；确认网络与端点 | Space/Shift+Space 控制走线模式，不是旋转元件 |
| PCB 普通 2D | L、Shift+S、Ctrl+PageDown | Ctrl+F 翻板；Tab 可能扩展选择 |
| PCB 布线/调长 | Shift+F1、Tab 查看当前属性 | L、数字键、Shift+C 具有命令专用含义 |
| PCB 3D 查看 | 读 View 菜单和当前帮助 | 主键盘/小键盘数字意义不同；不要套用 2D 过滤恢复 |
| Properties 数值框 | Tab/Shift+Tab、字段选择、单位核对 | 字母可能输入值，Enter 可能提交；不是菜单助记键 |
| 菜单/模态对话框 | 可见 KeyTips、方向键、焦点名称 | Enter 执行当前项目，Esc 只退出当前层级 |

### 项目与精确编辑工作流

**打开并浏览设计**：定位现有 Altium 窗口 → Projects 面板核对工程与路径 → 打开指定 SchDoc/PcbDoc → 确认活动标签、读写状态 → 普通浏览态用 Ctrl+PageDown → 根据目标对象进入 SCH/PCB 面板或已核实的查找命令。不要把打开同名库元件当成打开工程上的实际实例。

**定位元件/网络**：从面板名称、Designator、Comment、Net 等可读字段搜索/筛选 → 核对工程、对象类型、设计标号与网络 → 使用面板提供的定位/缩放入口 → 核对被选中对象的属性。先看筛选是 dim、mask、select 还是 zoom，避免以为其他对象已删除。跨原理图/PCB 的定位依工程关联与当前配置，不凭显示位置猜测同一对象。

**更改元件属性**：确认唯一对象与目标字段 → 打开 Properties → 读原值、单位和锁定状态 → 修改已请求的参数 → 提交并重新读值 → 核对连接、图层和未保存标记。对象坐标、旋转角与设计标号均可用文字验证；多选时属性面板可能批量改对象，先确认选择数量。

**放置元件或布线**：先确定元件/引脚/网络/图层/坐标 → 菜单进入对应命令 → Shift+F1 读取当前可用键 → 核对光标附着对象 → 必要时 Tab 精确设置属性 → 逐次落点并核对 → Esc 取消剩余交互阶段 → 查看最终连接/DRC 信息。快捷键只能进入动作，不能推断模糊图中的引脚位置。

**查看测量**：进入已核实的测量命令 → 读单位、坐标与起止对象 → 选择两点 → 核对报告距离及几何对象 → 退出测量模式。测量标注与真实铜线/机械对象必须区分；不要用 Delete 清理未知画布对象。

**检查与输出**：使用菜单或搜索到的项目验证/DRC 命令，读取具体规则、范围和 Messages/报告；错误列表为空可能只是未运行或筛选隐藏。按用户请求生成输出时，核对 OutJob、目标目录、图层、单位、钻孔及版本；不要把保存文档等同于制造文件已更新。

### 查找命令与自定义键位

找不到记忆中的菜单序列时，先显示菜单并读命令名/当前绑定，或用当前版本支持的命令搜索入口。不要假定 Office Alt+Q 或 VS Code Ctrl+Shift+P 在 Altium 可用。P→W、P→T、R→I 只在当前编辑器菜单已证实后作为一项短序列；进入独立对话框要重新观察。

对于复制/粘贴、Move/Drag、选中同网络对象、交互布线、长度调节、切层、过孔、3D 旋转、网格和捕捉设置，优先读取该模式 Shift+F1 帮助与菜单。Move 和 Drag 对电气连接维护的行为不同，不能为了方便把它们互换。未验证的快捷键不做全局保证。

### 图像模糊时的可行范围

先用活动文档名、编辑器类型、状态栏命令文字/坐标和属性面板值建立状态。必要时用 Shift+F1 获取当前命令的文字帮助、Shift+F5 回到画布、Ctrl+PageDown 显示全部，配合新截图或可访问性文本核对。

快捷键能可靠**进入命令**，不能替代对象身份、网络、焊盘、图层、坐标和连接正确性的证据。Enter 在交互命令中可以相当于点击/落点。对象位置不可辨认时不盲放元件、不布线、不依据模糊截图提交 PCB 改动；优先 Properties 中可核对的精确数值，或请求缺少的目标信息。

制造输出、ECO 执行、Workspace 发布、打印不是普通查看快捷键的后续默认动作。不要把 `Ctrl+Alt+S` 当成通用 Save All；某些 Workspace 直接编辑场景中它用于保存新的项目项修订。

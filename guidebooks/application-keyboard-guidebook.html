系统组合键可能使前台离开目标窗口。WorkBuddy 的窗口约束若拒绝跨窗口动作，使用主技能提供的窗口选择接口；不要通过更换虚假的窗口 ID 绕过。动作完成后获取新目标状态/截图令牌。

文本用 Unicode 输入工具，按键用键盘工具。当前文字工具每次最多 2000 字符且不接收换行/控制字符；多段文字按应用已确认的换行方式连接，再核对完整内容。不要用数字 VK 枚举来代替任意 Unicode 文本。

验证一项本机快捷键

先从菜单、应用帮助或快捷键设置核对绑定与上下文，再在空白临时文档或可逆导航动作中验证。记录应用版本、语言、键盘布局、焦点、按键、预期变化和实际变化。聊天发送、数据库写入、ECO、运行代码和制造输出不作为快捷键探针。导航打开成功与用户业务目标完成分开记录。

官方默认值与本机实测是两类证据；本手册不会把文档核对写成已经在用户各应用中全部试过。

Office 共通操作：Windows 桌面版

本章适用于 Microsoft 365 / Office Windows 桌面应用。网页 Office、Mac、WPS、LibreOffice 不保证同键；远程桌面可能截获系统键。Outlook 先区分经典版与新版。应用自定义绑定、语言、输入法、插件优先于默认表。

目标 默认键 正确使用
显示 Ribbon KeyTips Alt 或 F10 先释放，读取当前屏幕上字母；再依次选标签和命令，不把整个路径同时按住

KeyTips 流程：确认应用与文档 → Alt → 新观察读取标签字母 → 按字母 → 新观察读取命令字母 → 选择 → 核对对话框/结果。英文版常见 File/Home/Insert/Review/View 字母为 F/H/N/R/W，但不要把它们当作跨语言保证。若某版支持 Alt+Q，可以直接搜索“另存为”“插入表格”“选择窗格”等本地化命令；选择前核对具体命令，搜索结果可能含帮助条目。

sequence 适合已经核实且仍在同一窗口的一项短快捷操作；KeyTips 未确认、菜单需等待、弹窗更换前台窗口时拆开操作。序列中断后检查已打开的菜单，不重发完整链。

文档、剪贴板和保存

目标 常见键 边界
打开 Ctrl+O 可能先进入 Backstage；核对本地/云端路径
新建 Ctrl+N 新文档/工作簿/演示文稿；Outlook 依当前模块，新建对象可能不同
保存 Ctrl+S 初次保存可能出现对话框；Access 数据记录与对象设计另有语义
另存为 F12（Word/Excel/PowerPoint 桌面版） 核对路径、格式和覆盖提示；其他应用不套用
打印入口 Ctrl+P 打开预览不等于已经打印；核对打印机、范围、份数后才最终打印
关闭当前文档 Ctrl+F4 可能有未保存提示；不默认丢弃
复制/剪切/粘贴 Ctrl+C/X/V 先确认选区和剪贴板来源；V 可能携带格式、公式或链接
撤销 Ctrl+Z 只撤销明确属于当前任务的最近操作；云协作和数据库提交不保证可撤销
重做/重复 Ctrl+Y 不总是重做；可能重复最近动作

保存对话框中可用 Ctrl+L / Alt+D 聚焦路径栏（以当前对话框为准），但不是所有 Office 正文的地址栏快捷键。确认“文件名”控件后输入文件名，明确选择格式，再执行保存。观察文档标题/保存状态；有文件工具时验证目标文件存在、扩展名正确。不要仅因对话框消失就宣称文件格式正确。

AutoSave 打开时，修改可能立即同步；Ctrl+S 不是唯一写入时点。受保护视图、只读、共享权限、密码或 UAC 不能靠快捷键绕过，也不要为使快捷键成功自动启用宏。

键名、布局与多行

Ctrl+Shift+> 是字符表示；美式键盘常用工具参数 CTRL+SHIFT+PERIOD。Ctrl+; 为 CTRL+SEMICOLON，Ctrl+Shift+: 对应 CTRL+SHIFT+SEMICOLON；Ctrl+~ 对应 CTRL+SHIFT+BACKTICK。其他布局用应用菜单核对，不能假设字符=同一物理键。

Ctrl 加主键区加号用 CTRL+PLUS / CTRL++；数字小键盘加号是 CTRL+ADD。NUMPAD_ENTER、NUMPAD0…NUMPAD9 与主键区数字/Enter 不同。公式和文字用 Unicode 输入工具；快捷键工具不是任意文本输入器。

换行需读对应应用：Word Enter 新段落、Shift+Enter 软换行；Excel Alt+Enter 单元格内换行；Outlook Ctrl+Enter 可能发送邮件。不能跨应用照搬。

完成检查

导航：文档身份 + 实际目标位置。编辑：目标选区 + 内容/公式/对象属性。保存：路径/格式 + 保存状态。打印/发送/发布：按用户已有授权执行一次，再核对输出状态；失败/超时不自动重复最终动作。

工作流

修改特定段落：Ctrl+F 搜索唯一片段 → 核对页码/前后文 → 回到正文并准确选择 → 输入替换 → 核对内容及样式 → 按请求保存。查找框仍有焦点时 Ctrl+A 只会选搜索词。

制作结构化文档：输入标题/正文 → 用标题样式分级 → 插入真正分页符和表格 → 命令搜索插入目录 → 更新并查看分页 → 保存。不要用一串空格、Tab 和空段落模仿布局。

审阅并保留修订：确认文档/修订状态 → 开启或保留 Track Changes → 编辑 → 按需批注 → 阅读审阅窗格 → 保存；不自动接受所有修订。

导出 PDF：保存原稿 → F12 或命令搜索另存为/导出 → 核对 PDF 类型、路径及范围 → 执行 → 用可用文件/预览工具核对页数、分页、表格和文字。快捷键完成保存不证明视觉排版正确。

  2. 激活后确认账号和目标联系人/群。昵称重名时结合 QQ 号、群名或用户提供的身份；不会因为“打开了一个聊天”就认为目标正确。

修改草稿：确认输入框焦点 → Ctrl+Home/End、Ctrl+Left/Right 和加 Shift 的选择键可用于标准文本编辑；富文本控件、表情块和引用消息可能改变光标行为，按结果核对。Ctrl+A 后先确认仅选中草稿再替换。

托盘找不到：按主技能检查任务栏和隐藏图标；若提示显示在图标上方/旁边，读取名称并关联其指向的图标。QQ 可能正在登录、后台运行或有独立会话窗口；先恢复已有实例，不反复启动。需要菜单时在已识别图标上打开上下文菜单并读项目。

无响应恢复：先查模态文件选择器、截图层、输入法候选、快捷键冲突和焦点。已确认弹层用一次 Esc 退出后重新观察。聊天发送结果不明时先读消息气泡/失败标记；禁止用第二次发送作为验证。

来源与置信度

QQ 没有在本次核验中取得覆盖经典版和 QQNT 的统一官方键位表，也没有读取用户聊天内容来测试。Ctrl+Alt+Z 与 Ctrl+Alt+A 仅作为经典常见绑定候选；本机设置、菜单提示及发送方式选项是最终依据。不要编造未经确认的“快速打开联系人”组合键。

项目与精确编辑工作流

打开并浏览设计：定位现有 Altium 窗口 → Projects 面板核对工程与路径 → 打开指定 SchDoc/PcbDoc → 确认活动标签、读写状态 → 普通浏览态用 Ctrl+PageDown → 根据目标对象进入 SCH/PCB 面板或已核实的查找命令。不要把打开同名库元件当成打开工程上的实际实例。

定位元件/网络：从面板名称、Designator、Comment、Net 等可读字段搜索/筛选 → 核对工程、对象类型、设计标号与网络 → 使用面板提供的定位/缩放入口 → 核对被选中对象的属性。先看筛选是 dim、mask、select 还是 zoom，避免以为其他对象已删除。跨原理图/PCB 的定位依工程关联与当前配置，不凭显示位置猜测同一对象。

更改元件属性：确认唯一对象与目标字段 → 打开 Properties → 读原值、单位和锁定状态 → 修改已请求的参数 → 提交并重新读值 → 核对连接、图层和未保存标记。对象坐标、旋转角与设计标号均可用文字验证；多选时属性面板可能批量改对象，先确认选择数量。

放置元件或布线：先确定元件/引脚/网络/图层/坐标 → 菜单进入对应命令 → Shift+F1 读取当前可用键 → 核对光标附着对象 → 必要时 Tab 精确设置属性 → 逐次落点并核对 → Esc 取消剩余交互阶段 → 查看最终连接/DRC 信息。快捷键只能进入动作，不能推断模糊图中的引脚位置。

查看测量：进入已核实的测量命令 → 读单位、坐标与起止对象 → 选择两点 → 核对报告距离及几何对象 → 退出测量模式。测量标注与真实铜线/机械对象必须区分；不要用 Delete 清理未知画布对象。

检查与输出：使用菜单或搜索到的项目验证/DRC 命令，读取具体规则、范围和 Messages/报告；错误列表为空可能只是未运行或筛选隐藏。按用户请求生成输出时，核对 OutJob、目标目录、图层、单位、钻孔及版本；不要把保存文档等同于制造文件已更新。

查找命令与自定义键位

找不到记忆中的菜单序列时，先显示菜单并读命令名/当前绑定，或用当前版本支持的命令搜索入口。不要假定 Office Alt+Q 或 VS Code Ctrl+Shift+P 在 Altium 可用。P→W、P→T、R→I 只在当前编辑器菜单已证实后作为一项短序列；进入独立对话框要重新观察。

对于复制/粘贴、Move/Drag、选中同网络对象、交互布线、长度调节、切层、过孔、3D 旋转、网格和捕捉设置，优先读取该模式 Shift+F1 帮助与菜单。Move 和 Drag 对电气连接维护的行为不同，不能为了方便把它们互换。未验证的快捷键不做全局保证。

图像模糊时的可行范围

先用活动文档名、编辑器类型、状态栏命令文字/坐标和属性面板值建立状态。必要时用 Shift+F1 获取当前命令的文字帮助、Shift+F5 回到画布、Ctrl+PageDown 显示全部，配合新截图或可访问性文本核对。

快捷键能可靠进入命令，不能替代对象身份、网络、焊盘、图层、坐标和连接正确性的证据。Enter 在交互命令中可以相当于点击/落点。对象位置不可辨认时不盲放元件、不布线、不依据模糊截图提交 PCB 改动；优先 Properties 中可核对的精确数值，或请求缺少的目标信息。

制造输出、ECO 执行、Workspace 发布、打印不是普通查看快捷键的后续默认动作。不要把 Ctrl+Alt+S 当成通用 Save All；某些 Workspace 直接编辑场景中它用于保存新的项目项修订。
